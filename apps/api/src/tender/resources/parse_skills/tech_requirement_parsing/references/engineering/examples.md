# 技术要求解析样例（工程类）

## 样例 1：建筑工程施工技术要求

### 输入原文
```
第四章 技术要求
一、工程概况
本项目为XX市综合办公楼，地上18层，地下2层，框架-剪力墙结构，总建筑面积约32000㎡。

二、施工技术要求
1. 基础工程：采用钻孔灌注桩，桩径800mm，桩长≥25m，单桩承载力≥3500kN
2. 主体结构：混凝土强度等级不低于C40（柱）/C30（梁板），钢筋采用HRB400
3. ★抗震设防：抗震设防烈度7度，框架抗震等级二级
4. 防水工程：屋面防水等级I级，采用SBS改性沥青防水卷材，厚度≥4mm

三、安全文明施工要求
1. 施工现场应实行封闭管理，围挡高度不低于2.5m
2. 施工现场扬尘控制应达到《建筑施工现场环境与卫生标准》要求
3. 深基坑（深度≥5m）应编制专项施工方案并组织专家论证
```

### 期望输出

| 2 | 桩长 | ≥25 | m | 否 |
| 3 | 单桩承载力 | ≥3500 | kN | 否 |
| 4 | 柱混凝土强度 | ≥C40 | - | 否 |
| 5 | 梁板混凝土强度 | ≥C30 | - | 否 |
| 6 | 钢筋等级 | HRB400 | - | 否 |
| 7 | 抗震设防烈度 | 7度 | - | 是(★) |
| 8 | 框架抗震等级 | 二级 | - | 是(★) |
| 9 | 防水卷材厚度 | ≥4 | mm | 否 |

**安全文明施工：**
- 封闭管理，围挡≥2.5m
- 扬尘控制达标
- 深基坑≥5m需专项方案+专家论证
