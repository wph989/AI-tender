# 技术要求提取规则（货物类）

## 货物类技术要求的核心特征

货物类技术要求围绕**产品参数、性能指标、检测报告**展开，数值精确性要求最高。

---

## 一、货物类特有技术要求

### 1.1 产品技术参数
- **物理参数**：尺寸、重量、容量、功率等
- **性能参数**：效率、精度、速度、噪音等
- **环境参数**：工作温度、湿度、防护等级（IP等级）

### 1.2 产品质量标准
- **产品标准**：GB/T开头的推荐性标准
- **行业标准**：如JB（机械）、HG（化工）等
- **国际标准**：IEC、ISO标准

### 1.3 兼容性与接口要求
- **通信协议**：Modbus、BACnet、TCP/IP等
- **接口标准**：RS485、RJ45、USB等
- **软件兼容**：操作系统、数据库版本

### 1.4 检测与试验要求
- **出厂检测**：工厂内部检测项目
- **型式试验**：第三方检测机构完成
- **到货验收**：现场检测项目和标准

## 二、货物类关键词种子清单

- "技术参数""性能指标""规格参数"
- "额定功率""额定电压""额定电流"
- "效率""能效""COP""EER"
- "防护等级""IP等级""绝缘等级"
- "通信协议""接口""兼容性"
- "检测报告""型式试验""出厂检验"
- "★""▲""实质性参数"

---

## 三、严禁行为
- ❌ 四舍五入产品参数数值
- ❌ 遗漏单位（W/kW混淆会导致严重错误）
- ❌ 遗漏★/▲标记的实质性参数
- ❌ 遗漏兼容性和接口要求
- ❌ 混淆"额定值"和"最大值"

---

## 五、自检清单
1. 所有技术参数（含数值和单位）精确提取？
2. ★实质性参数完整识别？
3. 兼容性和接口要求提取？
4. 检测/试验要求提取？
5. 产品标准编号完整提取？
