# 技术要求解析样例

## 样例 1：技术参数表格

### 输入原文
```
三、主要技术参数
| 序号 | 设备名称 | 技术参数 | 单位 | 要求 | 备注 |
|------|---------|---------|------|------|------|
| 1 | 空调主机 | 制冷量≥500kW | kW | ≥500 | ★参数 |
| 2 | 空调主机 | COP能效比 | - | ≥5.2 | |
| 3 | 风管 | 材质厚度 | mm | ≥0.75 | |
| 4 | 控制系统 | 控制精度 | ℃ | ±0.5 | |
```

### 期望输出
4个参数全部提取，第1个标注为★关键参数：
```
| 1 | 制冷量 | ≥500 | kW | 是 | ★参数 |
| 2 | COP能效比 | ≥5.2 | - | 否 | |
| 3 | 材质厚度 | ≥0.75 | mm | 否 | |
| 4 | 控制精度 | ±0.5 | ℃ | 否 | |
```

## 样例 2：偏差表

### 输入原文
```
技术偏差表：
| 序号 | 参数名称 | 招标要求 | 允许偏差范围 |
|------|---------|---------|-------------|
| 1 | 制冷量 | ≥500kW | 不允许负偏差 |
| 2 | 噪音 | ≤65dB(A) | +3dB |
| 3 | 尺寸 | 2000×1000×800mm | ±50mm |
```

### 期望输出
3条偏差规则全部提取：制冷量不允许负偏差（即必须≥500kW）、噪音允许+3dB（即最大68dB）、尺寸允许±50mm偏差。

---

## 样例 3：禁止四舍五入

### 输入原文
```
系统综合能效比SEER≥4.35，全年运行效率≥92.5%
```

### 期望输出
- ✅ 正确：SEER≥4.35、效率≥92.5%
- ❌ 错误：SEER≥4.4、效率≥93%（禁止四舍五入）
