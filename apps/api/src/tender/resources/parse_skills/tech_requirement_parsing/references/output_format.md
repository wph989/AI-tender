# 技术要求输出格式

下列 Markdown 只定义展示分类、列名和层级；实际通过工具提交 content JSON。
正文按全部证据综合，引用独立保存；无依据内容省略，未决事项登记为检索缺口。

```markdown
## 项目背景
1. [背景摘要]

## 技术方案要求
### 1. [技术主题/独立任务名称]
- **章节来源**：[原文章节名称或条款编号；无则省略本行]
- **要求摘要**：[基于原文概括本章节需在技术方案中说明的内容]
- **关键要求**：
  1. [关键要求或独立任务内容]
  2. [关键要求]
```

## 内容约束
- 项目背景仅在原文有明确背景或建设目标时输出；缺失时省略。
- 项目背景以 1 至若干条短段落输出，存在集中表述时优先引用原文。
- 技术方案要求按主题或独立任务分章节；明确拆分的课题、任务、子项目、工作包必须逐一保留，不得合并、不得遗漏。
- 对非独立任务单元的一般技术要求，可按内容相近性归并为主题章节。
- 技术参数、功能、性能、标准等内容只有在能指导技术方案编写时，才放入对应主题的 `关键要求条目`，不得单独扩展为一级分类。
- 非技术方案内容即使命中技术章节，也不得写入结果。
