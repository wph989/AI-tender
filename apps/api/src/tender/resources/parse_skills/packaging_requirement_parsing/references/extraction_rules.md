# 封装要求提取规则

## 核心原则：完整提取，封装不符是废标高频原因

---

## 一、识别与定位
### 常见位置：投标人须知、投标文件编制要求、封装密封专节
### 关键词种子（可扩展，不限于）："封装""密封""装订""正本""副本""份数""分册""标记""密封袋""封条"

## 二、精确提取规则
- 份数：正本X份 + 副本X份，精确到数字
- 分册：技术标/商务标/价格标是否分开，如何分
- 密封：内层/外层密封袋要求、密封条/封签
- 标记：封面/密封袋上应标注的内容清单
- 电子版：U盘/光盘/CD、文件格式（PDF/Word/Excel）
- 装订：胶装/活页/骑马钉、是否允许活页

## 三、严禁行为
- ❌ 遗漏电子版要求
- ❌ 混淆正本和副本的不同要求
- ❌ 遗漏"不得出现投标人名称"等盲标要求
- ❌ 遗漏封面标记内容的任何一项

## 四、自检清单
1. 份数精确？2. 分册方式清晰？3. 密封要求完整？4. 标记内容逐项列出？5. 电子版要求提取？
