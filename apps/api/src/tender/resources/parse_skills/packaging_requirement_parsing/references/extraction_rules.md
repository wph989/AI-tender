# 封装与递交提取细则

以下内容是检索和判断指导，示例名词不代表本项目事实。只使用本次已读原文作依据。

提取投标文件制作、签章、份数、装订、密封、标记和递交载体要求；内部章节树交给格式专题。
- 正本、副本、纸质、电子文件和介质份数分别核对，不将逻辑标分类自动当成独立密封分册。 <!-- topics: copies -->
- 签字主体、盖章种类、骑缝章、封口及外封标记逐项保留，不能用“按要求签章”替代。 <!-- topics: signing,sealing -->
- 盲标中禁止出现的名称、标识与可出现的例外按原文记录，不能将普通技术标自动当成盲标。
- 电子格式、加密、文件命名、签章、上传渠道和介质应区分，不能用纸质份数推算电子份数。 <!-- topics: copies,signing,submission -->
- 制作或递交要求本身不证明否决后果；原文明示否决时保留相关依据，但不臆造后果。
- 分散附件和补遗需核对，条件不同的要求单独记录；没有相关要求时登记缺口。

## 检索与自检

按上述业务主题检索项目主文件、澄清、补遗及相关附件；名称只是线索，关键词未命中不能证明全文未约定。
遇到转引继续检索目标，围绕已读 block_id 补读表头、脚注和限定条件；不能通过文件路径或推测ID读取原文。
综合前核对主体、标段、条件、单位与修订关系；无依据字段省略，未决事项保留具体缺口。
同一完整事项可以引用多个原文块；按 output_format.md 逐条提交 content JSON，原文引用独立保存。
