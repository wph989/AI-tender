# 封装要求解析样例

## 样例 1
### 输入原文
```
投标文件的编制与密封要求：
1. 投标文件应分册装订：商务技术标（正本1份，副本4份）和价格标（正本1份，副本4份）分别密封
2. 装订方式：胶装，不得采用活页装订
3. 密封要求：内外两层密封袋，内层密封袋封口处加盖投标人公章
4. 外层密封袋封面应注明：项目名称、招标编号、投标人名称、"商务技术标"或"价格标"字样、"在2026年3月15日9时30分前不得开启"
5. 另附U盘1个，内含投标文件PDF版和可编辑Word版
```

### 期望输出
- 分册：商务技术标（正1副4）+ 价格标（正1副4），分别密封
- 装订：胶装，禁止活页
- 密封：内外双层，内层封口处盖公章
- 标记：5项（项目名称、招标编号、投标人名称、标类型、开启时间）
- 电子版：U盘1个，PDF+Word
