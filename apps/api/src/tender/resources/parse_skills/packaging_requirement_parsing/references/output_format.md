# 封装要求输出格式

## 通用返回要求
- 最终只发送一条普通 assistant 文本消息，内容为下述 Markdown 格式的结果正文。
- 正文前不得出现前言或代码围栏；正文必须是非空 Markdown，禁止空消息或只写“已完成”。
- 解析结论只输出投标文件组成、格式、签章、密封、份数、纸质版和电子版要求。
- 无对应内容的分类整段省略；全部无相关内容时，只输出 `无相关内容`。

```markdown

## 投标文件组成
| 文件部分 | 具体要求 |
|----------|----------|
|  |  |

## 文件格式要求
| 格式要求 | 具体描述 |
|----------|----------|
|  |  |

## 签字盖章要求
| 签字盖章要求 | 具体描述 |
|--------------|----------|
|  |  |

## 密封要求
| 密封要求 | 具体描述 |
|----------|----------|
|  |  |

## 份数要求
| 份数要求 | 具体描述 |
|----------|----------|
|  |  |

## 纸质版要求
| 纸质要求 | 具体描述 |
|----------|----------|
|  |  |

## 电子版要求
| 电子要求 | 具体描述 |
|----------|----------|
|  |  |
```

## 输出细节
- 不得简化签字、盖章、密封、份数、电子介质等可能影响废标的关键要求。
- 文件格式要求仅指投标文件制作和提交格式；不解析投标文件格式大纲章节树。
- 每个分类只保留有实质要求的表格行，禁止输出空行或示例占位符。
