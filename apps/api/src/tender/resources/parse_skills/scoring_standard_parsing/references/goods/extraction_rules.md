# 评分办法提取细则（goods）

以下内容是检索和判断指导，示例名词不代表本项目事实。只使用本次已读原文作依据。

围绕本次评标的评分总则、总分构成、评分项与价格公式检索，不从示例分值或行业惯例补齐。
- 读取表头、跨页续表、脚注和转引，区分大类总分、单项满分、档次分值与扣分。
- 一个评分项是一条完整事项；档次、条件分支、同项扣分和备注用字符串数组保留，不能按表格物理行拆成多个评分项。
- 保留公式、变量定义、取值条件、基准价形成方式、舍入办法与封顶保底；缺少公式条件时登记缺口。
- 原文分商务/技术则分别归类，原文合并则用综合评分；价格评分的公式和各得分情形保留在同一评分项。
- 有分值的加分、扣分都保留；明确否决投标属于否决专题，合同考核与验收打分不是评标评分。
- 分值加总只用于核对；不一致时保留原值及缺口，不自行修正总分、套用常见权重。

## 品类重点

重点核对技术偏离、样品测试、产品性能、售后服务、供货业绩及报价的评分；区分★项否决与普通负偏离扣分，不能默认二者相同。

## 检索与自检

按上述业务主题检索项目主文件、澄清、补遗及相关附件；名称只是线索，关键词未命中不能证明全文未约定。
遇到转引继续检索目标，围绕已读 block_id 补读表头、脚注和限定条件；不能通过文件路径或推测ID读取原文。
综合前核对主体、标段、条件、单位与修订关系；无依据字段省略，未决事项登记 coverage/gaps。
同一完整事项可以引用多个原文块；按 output_format.md 逐条提交 content JSON，原文引用独立保存。
