# 评分标准输出格式

下列 Markdown 只定义展示分类、列名和层级；实际通过工具提交 content JSON。
正文按全部证据综合，引用独立保存；无依据内容省略，未决事项登记为检索缺口。

```markdown
## 评分总则
| 总则要素 | 原文内容 |
|----------|----------|
| 评标方法 |  |
| 总体规则/计算公式 |  |

## 总分构成
| 组成部分 | 分值 |
|----------|------|
|  |  |
| 总分 |  |

**本部分总分：[原文分值]**

| 序号 | 评分项 | 满分分值 | 评分标准（原文摘录） |

**价格评分总分：[原文分值]**

| 序号 | 评分项 | 满分分值 | 评分标准（原文摘录） |
|------|--------|----------|----------------------|
| 1 |  |  |  |
```

## 内容约束
- 根据原文结构组织评分细则；原文区分商务/技术时分别输出，合并时只输出 `综合评分标准`。
- 价格评分只保留一个总分入口，基准价、公式及所有得分情形均写入同一评分项，禁止拆分价格评分。
- 评分细则应尽量保留原文，不得删除有分值的评分要求。
- 同一评分项内的总体说明、各评分档次、条件分支和备注必须按原文逻辑边界使用字符串数组逐条保留，禁止合并成连续段落。
- 评分档次是上级评分项的规则，不得拆成独立评分项；排除扣分项和废标项。
