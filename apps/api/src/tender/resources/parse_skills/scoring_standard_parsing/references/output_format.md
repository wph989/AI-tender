# 评分标准输出格式

## 通用返回要求
- 最终只发送一条普通 assistant 文本消息，内容为下述 Markdown 格式的结果正文。
- 正文前不得出现前言或代码围栏；正文必须是非空 Markdown，禁止空消息或只写“已完成”。
- 解析结论只输出评标方法、总分构成、评分细则、价格分计算和加扣分规则。
- 无对应内容的分类整段省略；全部无相关内容时，只输出 `无相关内容`。

```markdown

## 评分总则
| 总则要素 | 原文内容 |
|----------|----------|
| 评标方法 |  |
| 总体规则/计算公式 |  |

## 总分构成
| 组成部分 | 分值 |
|----------|------|
|  |  |
| 总分 |  |

## [商务/技术/综合]评分标准
**本部分总分：[原文分值]**

| 序号 | 评分项 | 满分分值 | 评分标准（原文摘录） |
|------|--------|----------|----------------------|
| 1 |  |  |  |

## 价格评分标准
**价格评分总分：[原文分值]**

| 序号 | 评分项 | 满分分值 | 评分标准（原文摘录） |
|------|--------|----------|----------------------|
| 1 |  |  |  |
```

## 输出细节
- 根据原文结构组织评分细则；原文区分商务/技术时分别输出，合并时只输出 `综合评分标准`。
- 价格评分只保留一个总分入口，基准价、公式及所有得分情形均写入同一评分项，禁止拆分价格评分。
- 评分细则应尽量保留原文，不得删除有分值的评分要求。
- 同一评分项内的总体说明、各评分档次、条件分支和备注必须按原文逻辑边界使用 `<br>` 分隔，禁止合并成连续段落。
- 每个 Markdown 表格数据行必须保持在同一个物理文本行内；单元格原文中的 `|` 必须写为 `\|`，表格分隔列使用的 `|` 不得转义。
- 评分档次是上级评分项的规则，不得拆成独立评分项；排除扣分项和废标项。
