# 评分标准解析 Skill

## 适用场景
- 触发：项目控制器启动当前专题评分标准解析任务时调用。
- 输入：授权资料清单与按需检索得到的原文块，不预先灌入全文。
- 输出：可增量暂存的 content JSON，block_ids 保留已读原文身份，整项审查后发布。

## 领域知识

评分标准是招标文件中规定评标方法和分值分配的核心内容，主要包括：

1. **评标方法**：综合评分法、最低评标价法、性价比法等
2. **分值分配**：技术分、商务分、价格分的权重和分值
3. **评分细则**：每个评分项的评分标准（满分条件、扣分规则）
4. **价格分计算**：基准价确定方法、价格分计算公式
5. **加分/扣分项**：优惠政策、中小企业加分等

有效评分标准必须包含具体分值、计算公式或“评分项+评分细则”结构。仅有评标流程、资格/符合性审查、目录索引、供应商绩效考核、项目验收评分、合同条款或文件格式要求时不得提取。

## 识别规则

以下为章节定位和原文识别线索，选择与具体缺口有关的表达，不逐词搜索：
- "评标办法"、"评标方法"、"评分标准"、"评分细则"
- "综合评分法"、"最低评标价法"
- "分值"、"权重"、"得分"
- 分值表格
- "价格分"、"技术分"、"商务分"

## 执行流程

1. **主题检索**：使用 `search_document_batch` 搜索"评标办法""评分标准"等章节标题
2. **展开转引与上下文**：命中“详见第三章/某附件”“按前附表执行”等指向时，用文件名、章节名、条号加评分主题继续 `search_document_batch`；跨文件先 `list_documents` 确认授权资料并限定 source_id。命中目标后用 `read_document` 补读评分表、表头、脚注和相邻条件；目录或转引句只作线索，不作评分结果
3. **有效性判断**：确认存在分值、公式或实质评分细则
4. **先总后细**：先提取评标方法、总分构成和总体公式，再完整提取评分表
5. **层级校验**：区分总分、评分项和评分档次；评分档次不得重复计为独立评分项
6. **结构选择**：原文分开商务/技术时分别输出，合并时输出综合评分
7. **输出结果**：按本 Skill 的输出协议调用 submit_analysis；没有依据的条目省略。

遇到多级转引继续追踪到实际规则；同一指向循环、目标文件未提供或预算耗尽时，将追踪路径和缺口写入 research_summary，不以“详见……”占位，不以历史资料或常识补齐。

## 取证重点与完成判断

优先定位评标办法、完整评分表、价格公式及评分附件，按连续条款读取；一次读取可解决多个核对项。
评分项、档次、公式、表头脚注和转引细则已完整核对后即可统一综合；尚缺内容明确到具体条款或材料再补查，缺失资料如实登记。

## 本项目的检索与输出

按 coverage.json 核对业务内容，保留范围、条件、例外及完整清单。研究与提交协议以运行时工具为准；本文件只定义本专题的业务判断。
