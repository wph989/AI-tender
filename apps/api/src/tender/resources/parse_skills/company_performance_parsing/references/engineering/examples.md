# 企业业绩解析样例（工程类）

## 样例 1：施工招标业绩要求

### 输入原文
```
投标人业绩要求：
投标人近5年（2021年1月1日至今）应具有不少于3个类似工程施工业绩。
类似工程定义：单项合同金额不低于2000万元的房屋建筑工程施工项目（含基础和主体结构工程）。
证明材料：提供中标通知书、施工合同协议书和竣工验收报告复印件，三者缺一不可。
注：联合体业绩按投标人实际承担的工作内容认定，已完工未结算的项目需提供建设单位证明。
```

### 期望输出
- 数量：≥3个
- 时间：2021年1月1日至今（近5年）
- 类似工程定义：单项合同金额≥2000万元 + 房屋建筑工程 + 施工（含基础和主体结构）
- 证明材料：中标通知书 + 施工合同协议书 + 竣工验收报告（复印件，三者缺一不可）
- 联合体业绩：按实际承担内容认定
- 已完工未结算：需建设单位证明
