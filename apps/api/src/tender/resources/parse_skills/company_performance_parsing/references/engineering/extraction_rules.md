# 业绩要求提取细则（engineering）

以下内容是检索和判断指导，示例名词不代表本项目事实。只使用本次已读原文作依据。

仅提取企业历史项目经验，人员个人履历和个人业绩交给人员专题。
- “类似项目”的行业、类型、规模、金额、数量及地域等定义以原文为准，不能按名称相似推定满足。
- 日期窗口保留起止时间和认定节点：合同签订、交付、完工或验收；不自行将“近三年”换算成年份。
- 合同数量、单项金额、累计金额、含税口径和联合体份额不能相互替代。
- 证明材料保留原文的且/或关系、签章、关键页、原件/复印件和缺件处理；不得默认需要“三证齐全”。
- 在建、已完成、验收合格和联合体业绩的认定必须有原文定义，不能套用常见行业口径。
- 区分准入业绩和计分业绩；同一业绩的条件、材料和分值可归并为完整事项，保留所有必要引用。

## 品类重点

核对工程类型、结构、建筑面积/道路长度/跨度、单项金额和竣工节点；中标通知书、合同、验收报告仅按原文组合取证，联合体只按明确承担范围认定。

## 检索与自检

按上述业务主题检索项目主文件、澄清、补遗及相关附件；名称只是线索，关键词未命中不能证明全文未约定。
遇到转引继续检索目标，围绕已读 block_id 补读表头、脚注和限定条件；不能通过文件路径或推测ID读取原文。
综合前核对主体、标段、条件、单位与修订关系；无依据字段省略，未决事项保留具体缺口。
同一完整事项可以引用多个原文块；按 output_format.md 逐条提交 content JSON，原文引用独立保存。
