# 企业业绩解析样例（货物类）

## 样例 1：设备采购业绩要求

### 输入原文
```
投标人业绩要求：
投标人近3年（2023年1月1日至今）应具有不少于3个同类空调设备供货业绩。
同类设备定义：单台制冷量≥2000kW的离心式冷水机组。
单个供货合同金额不低于500万元。
证明材料：提供供货合同和用户验收报告复印件。
注：如为代理商投标，可使用制造商的供货业绩。
```

### 期望输出
- 数量：≥3个
- 时间：2023年1月1日至今（近3年）
- 同类设备定义：单台制冷量≥2000kW的离心式冷水机组
- 金额要求：单个合同≥500万元
- 证明材料：供货合同 + 用户验收报告（复印件）
- 代理商：可使用制造商业绩
