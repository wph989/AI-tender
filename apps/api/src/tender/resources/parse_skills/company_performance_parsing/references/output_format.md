# 企业业绩输出格式

下列 Markdown 只定义展示分类、列名和层级；实际通过工具提交 content JSON。
正文按全部证据综合，引用独立保存；无依据内容省略，未决事项登记为检索缺口。

```markdown
## 类似项目业绩要求
| 业绩要求 | 具体描述 |
|----------|----------|
|  |  |

## 业绩时间范围要求
| 时间要求 | 具体描述 |
|----------|----------|
|  |  |

## 业绩金额要求
| 金额要求 | 具体描述 |
|----------|----------|
|  |  |

## 证明材料要求
| 材料要求 | 具体描述 |
|----------|----------|
|  |  |

## 业绩评分标准
| 评分标准 | 具体描述 |
|----------|----------|
|  |  |

## 特定行业业绩要求
| 行业要求 | 具体描述 |
|----------|----------|
|  |  |
```

## 内容约束
- 业绩要求必须针对投标人企业历史项目经验；人员个人业绩不得写入本模块。
- 合同金额、数量、年限、完成时间等必须保留原文口径，不得自行换算。
- 业绩评分标准仅输出直接以企业业绩为评分对象的规则。
