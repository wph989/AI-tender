# 企业业绩输出格式

## 通用返回要求
- 最终只发送一条普通 assistant 文本消息，内容为下述 Markdown 格式的结果正文。
- 正文前不得出现前言或代码围栏；正文必须是非空 Markdown，禁止空消息或只写“已完成”。
- 解析结论只输出投标人企业业绩要求，不输出企业资质、人员配置、财务状况或价格要求。
- 无对应内容的分类整段省略；全部无相关内容时，只输出 `无相关内容`。

```markdown

## 类似项目业绩要求
| 业绩要求 | 具体描述 |
|----------|----------|
|  |  |

## 业绩时间范围要求
| 时间要求 | 具体描述 |
|----------|----------|
|  |  |

## 业绩金额要求
| 金额要求 | 具体描述 |
|----------|----------|
|  |  |

## 证明材料要求
| 材料要求 | 具体描述 |
|----------|----------|
|  |  |

## 业绩评分标准
| 评分标准 | 具体描述 |
|----------|----------|
|  |  |

## 特定行业业绩要求
| 行业要求 | 具体描述 |
|----------|----------|
|  |  |
```

## 输出细节
- 业绩要求必须针对投标人企业历史项目经验；人员个人业绩不得写入本模块。
- 合同金额、数量、年限、完成时间等必须保留原文口径，不得自行换算。
- 业绩评分标准仅输出直接以企业业绩为评分对象的规则。
