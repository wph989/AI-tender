# 业绩要求 JSON 示例

以下是模拟原文块与工具提交样例，名称、数值及证据ID仅用于说明，不能用于实际项目。
每个JSON容器的blocks表示已读原文，submissions只演示草稿保存参数；完整自查、修订和最终提交方法见公共流程Skill。
样例展示完整业务事项与block_ids；修改沿用回执id和当前version，最终提交使用实际返回的草稿ID。
正文由 content 承载，block_ids 指向实际已读原文；标题、身份与定位由后端补齐，整项审查通过后展示。条件、材料、评分和例外完整写入 content，不重复提交结构化属性。

## 企业业绩门槛与证明材料

以下只展示局部草稿。先保存，再由本Agent自查和修正；单独最终提交时明确选择已自查的草稿ID。unknown不能作为公共或指定标段要求使用。

```json
{
  "blocks": [
    {
      "id": "example-1",
      "text": "投标人须提供2023年1月1日以来已完成的园区运维服务项目业绩至少2项，每项合同金额不低于100万元。"
    },
    {
      "id": "example-2",
      "text": "上述业绩以验收日期为准，须同时提供合同关键页和验收证明。"
    }
  ],
  "submissions": [
    {
      "records": [
        {
          "kind": "requirement",
          "group": "类似项目业绩要求",
          "content": {
            "业绩要求": "已完成的园区运维服务项目",
            "具体描述": [
              "2023年1月1日以来至少2项，每项合同金额不低于100万元",
              "以验收日期为准，同时提供合同关键页和验收证明"
            ]
          },
          "scope": {
            "kind": "unknown",
            "lot_refs": []
          },
          "block_ids": [
            "example-1",
            "example-2"
          ]
        }
      ],
      "final": false
    }
  ]
}
```
