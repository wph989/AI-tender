# 企业业绩解析样例

## 样例 1
### 输入原文
```
投标人业绩要求：
投标人近5年（2021年1月1日至今）应具有不少于3个类似项目业绩。
类似项目定义：单项合同金额不低于800万元的市政道路工程施工项目。
证明材料：提供中标通知书和合同协议书复印件，已完工项目另需提供竣工验收报告。
```

### 期望输出
- 数量：≥3个
- 时间：2021年1月1日至今（近5年）
- 类似项目定义：单项合同金额≥800万元 + 市政道路工程 + 施工
- 证明材料：中标通知书 + 合同协议书（复印件），已完工需竣工验收报告
- 性质：强制性要求（位于资格要求章节）
