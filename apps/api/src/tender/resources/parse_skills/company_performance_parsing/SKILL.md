# 企业业绩解析 Skill

## 适用场景
- 触发：主 Agent 委派企业业绩解析任务时调用。
- 输入：归一化 Markdown 文件，由运行时文件清单和受限工具提供。
- 输出：企业业绩要求结构化文档（markdown 格式），直接作为最终回复返回，由父级代码统一入库。

## 领域知识

企业业绩要求是招标文件中对投标人历史项目经验和能力的规定，主要包括：

1. **类似项目定义**：什么是"类似项目"（行业、规模、金额等界定标准）
2. **业绩数量要求**：需提供几个类似项目业绩
3. **时间范围**：业绩的时间窗口（如近3年、近5年）
4. **金额要求**：单个项目的最低合同金额
5. **证明材料**：需提供什么证明（合同、中标通知书、验收报告等）
6. **认定标准**：已完工/在建/已签约的不同认定规则

要求的主语必须是投标人企业的过往项目经验。企业资质、人员个人业绩、财务状况、设备设施、信誉、技术方案及其他资格条件必须排除。

## 识别规则

关键词种子（可扩展，不限于）："业绩"、"类似项目"、"同类项目"、"合同"、"中标通知书"、"验收"

## 执行流程

1. **精确检索**：使用 `grep` 搜索"业绩""类似项目"等章节
2. **扩展上下文**：根据命中位置使用 `read_file` 读取相邻条款
3. **主语判断**：确认要求针对企业历史项目，而非人员或企业资质
4. **完整提取**：保留业绩类型、数量、时间、金额、认定口径、证明材料及评分规则
5. **输出结果**：按规范格式生成完整 Markdown，直接作为最终回复返回，由父级代码统一入库

## 输出规范

- 输出格式已拆分到 `references/output_format.md`。
- 执行输出前必须读取并严格遵循该文件中的专属模板和输出细节。
- 命中规则时，结果正文只能包含按专属模板整理的实际解析结果，禁止附加解释性说明。
- 未命中任何企业业绩要求时，结果正文只能是 `无相关内容`，禁止补充未命中原因、检索过程或建议。

## 参考文件（按标类型加载）
根据当前项目的标类型（bid_type），加载对应子目录下的参考文件：
- `references/output_format.md`：本 Skill 专属输出模板和格式约束
- `references/<type_dir>/extraction_rules.md`：“类似项目”定义提取、时间窗口、证明材料、强制/加分区分、严禁行为、自检清单
- `references/<type_dir>/examples.md`：完整业绩要求提取样例
- bid_type 取值：service（服务类）、engineering（工程类）、goods（货物类）
- 如无法确定标类型，默认加载 service 目录

## 工具
- `grep`：在归一化 Markdown 中精确检索；具体路径、glob 和输出模式由运行时上下文与工具护栏约束
- `read_file`：围绕命中位置分页扩展读取上下文
- `list_extracted_files`：列出当前任务可用 Markdown 文件
- 无保存工具：模块结果直接作为最终回复返回，无相关内容也必须在最终回复正文中返回

## 注意
- "类似项目"的定义是关键，必须精确提取
- 注意区分"必须提供"和"提供加分"
- 注意证明材料的具体要求（合同关键页还是全文）
- 业绩评分只提取评分对象明确为企业业绩的规则
