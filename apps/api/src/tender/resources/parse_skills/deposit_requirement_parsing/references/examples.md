# 保证金解析样例

## 样例 1：同时存在投标保证金和履约保证金

### 输入原文
```
投标保证金：人民币壹拾万元整（¥100,000.00元）。投标人可采用银行转账或银行保函，采用转账方式的，应于2026年3月14日17:00前到账。未中标人的投标保证金在中标通知书发出后5个工作日内退还，不计利息。

履约保证金为中标合同金额的10%。中标人应在合同签订前以银行转账或不可撤销银行保函形式提交，履约保证金在项目验收合格后30日内无息返还。
```

### 期望输出
```markdown
## 投标保证金
| 项目 | 具体要求 |
|------|----------|
| 金额或比例 | 人民币壹拾万元整（¥100,000.00元） |
| 形式 | 银行转账或银行保函 |
| 提交截止时间 | 2026年3月14日17:00前到账 |
| 退还条件及时间 | 未中标人的投标保证金在中标通知书发出后5个工作日内退还，不计利息 |

## 履约保证金
| 项目 | 具体要求 |
|------|----------|
| 金额、比例及计算基数 | 中标合同金额的10% |
| 形式 | 银行转账或不可撤销银行保函 |
| 提交方式及时间 | 中标人应在合同签订前提交 |
| 返还或解除条件 | 项目验收合格后30日内无息返还 |
```

## 样例 2：明确不要求投标保证金

### 输入原文
```
本项目不要求投标人提交投标保证金。中标人须在收到中标通知书后5日内提交合同金额5%的履约保证金。
```

### 期望输出
```markdown
## 投标保证金
本项目不要求投标人提交投标保证金。

## 履约保证金
| 项目 | 具体要求 |
|------|----------|
| 金额、比例及计算基数 | 合同金额5% |
| 提交方式及时间 | 中标人须在收到中标通知书后5日内提交 |
```
