# 保证金提取细则

以下内容是检索和判断指导，示例名词不代表本项目事实。只使用本次已读原文作依据。

分别检索投标保证金与履约保证金，按义务阶段判断类型，不能只按“保证金”关键词混合金额与期限。
- 保留金额或比例、计算基数、大写小写、形式、受益人、收款信息、提交时间、有效期及退还条件。
- 保函、转账、保险等选择保留且/或、条件和限制；不从其他项目补银行账号或保函有效期。 <!-- topics: form,deadline -->
- 日期和时分仅按原文精度输出；相对期限保留起算点，缺失的时刻不能自行补为截止日某时。 <!-- topics: deadline -->
- 不予退还、没收、扣除、索赔、返还或解除要求分别归入对应保证金类型。 <!-- topics: refund -->
- 原文明示“不收取/无需提交”时保存完整免除事实和引用；未检索到时只登记缺口，不产出“无相关内容”。 <!-- topics: amount -->
- 质保金、工资保证金等不混入两类保证金；不同标段、主体、条件下的要求与免除分别记录。
