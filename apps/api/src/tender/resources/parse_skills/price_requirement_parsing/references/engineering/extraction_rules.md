# 报价要求提取细则（engineering）

以下内容是检索和判断指导，示例名词不代表本项目事实。只使用本次已读原文作依据。

检索限价、费用构成和折扣下浮，报价方式、币种及税费作为对应价格事项的限定一起保留。
- 区分预算、最高限价、单价限价、总价限价和中标价；大写小写不一致时保留冲突，不能擅自修正。 <!-- topics: ceilings -->
- 金额、比例、单位、含税口径、计费基数及折扣运算保留原文，不换算单位或补上缺失税率。 <!-- topics: components,adjustment -->
- 不同标段的不同金额分别形成记录并声明 scope.lot_refs；明确共同适用且要求相同才能共用一条。
- “超限处理”只写原文明示的后果，不能从“最高限价”自动推导否决；没有后果就省略该键。 <!-- topics: ceilings -->
- 费用包含项、另计项、不可竞争项、漏项处理及调整条件逐项核对，不默认各费用不可修改。 <!-- topics: components,adjustment -->
- 金额限价归投标限价，比例下浮归折扣/下浮，同一事项不重复放入两类；报价格式与评分公式不在此另建分类。

## 品类重点

核对清单/定额/费率计价、综合单价、措施费、规费、税金、暂列金额和暂估价；不可竞争、不得修改和工程量调整规则都须原文明示。

## 检索与自检

遇到转引继续检索目标，围绕已读 block_id 补读表头、脚注和限定条件；不能通过文件路径或推测ID读取原文。
综合前核对主体、标段、条件、单位与修订关系；无依据字段省略，未决事项保留具体缺口。
