# 价格要求提取规则（货物类）

## 货物类价格要求的核心特征

货物类报价以**设备单价+运杂费+安装调试费**为主，注意区分到岸价/离岸价、含税/不含税。

---

## 一、货物类特有价格要素

### 1.1 报价组成
- **设备费**：设备本体价格（含税/不含税）
- **运杂费**：运输、装卸、保险
- **安装调试费**：安装、调试、试运行
- **培训费**：操作培训、维护培训
- **备品备件费**：随机备件

### 1.2 报价方式
- **固定总价**：包含所有内容
- **分项报价**：按设备清单项逐项报价
- **含税/不含税**：明确增值税率（通常13%）

### 1.3 进口设备特殊要素
- **CIF/FOB**：到岸价/离岸价
- **关税**：进口关税率
- **汇率**：报价币种和汇率约定

## 三、严禁行为
- ❌ 混淆含税价和不含税价
- ❌ 遗漏安装调试费和培训费
- ❌ 遗漏"分项报价不得漏项"的要求
- ❌ 金额四舍五入
