# 价格要求解析样例

## 样例 1
### 输入原文
```
报价要求：
1. 本项目最高限价为人民币3,500,000.00元（叁佰伍拾万元整），超过最高限价的投标将被否决
2. 报价方式：固定总价，包含设备费、安装费、运输费、培训费及增值税（税率13%）
3. 报价货币：人民币
4. 报价有效期：自投标截止日起90个日历天
5. 投标人应按"分项报价表"格式逐项报价，不得漏项
```

### 期望输出
- 最高限价：3,500,000.00元（超限则废标）
- 报价方式：固定总价
- 包含内容：设备费+安装费+运输费+培训费+增值税(13%)
- 货币：人民币
- 有效期：90日历天
- 报价清单：分项报价表，不得漏项
