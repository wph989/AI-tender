# 价格要求解析样例（货物类）

## 样例 1：设备采购报价

### 输入原文
```
报价要求：
1. 本项目最高限价为人民币12,000,000.00元（壹仟贰佰万元整），超过最高限价的投标将被否决
2. 报价方式：分项报价，投标人应按设备清单逐项报价（含设备费、运输费、安装调试费、培训费）
3. 报价应为含税价（增值税率13%），同时列出不含税价
4. 报价货币：人民币
5. 报价有效期：自投标截止日起90个日历天
6. 分项报价表格式：
| 序号 | 设备名称 | 数量 | 单位 | 单价（含税） | 合价（含税） | 备注 |
7. 投标人不得漏报任何一项，漏报项视为已包含在总价中
```

### 期望输出
- 最高限价：12,000,000.00元（超限则废标）
- 报价方式：分项报价（设备清单逐项）
- 报价包含：设备费+运输费+安装调试费+培训费
- 含税价：增值税率13%，同时列出不含税价
- 货币：人民币
- 有效期：90日历天
- 报价表格：7列（序号/名称/数量/单位/单价/合价/备注）
- 漏报处理：视为已包含在总价中
