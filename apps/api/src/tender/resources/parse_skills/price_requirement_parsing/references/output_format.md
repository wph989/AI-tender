# 价格要求输出格式

## 通用返回要求
- 最终只发送一条普通 assistant 文本消息，内容为下述 Markdown 格式的结果正文。
- 正文前不得出现前言或代码围栏；正文必须是非空 Markdown，禁止空消息或只写“已完成”。
- 解析结论只输出约束投标报价本身的内容，禁止混入保证金、企业注册资本、业绩金额、格式模板占位金额等非报价要求。
- 无对应内容的分类整段省略；全部无相关内容时，只输出 `无相关内容`。

```markdown

## 投标限价
| 限价类型 | 金额或范围（原文） | 超限处理 |
|----------|--------------------|----------|
|  |  |  |

## 价格构成
| 费用项 | 计算方式或比例（原文） |
|--------|------------------------|
|  |  |

## 折扣/下浮
| 下浮类型 | 范围或要求（原文） |
|----------|--------------------|
|  |  |
```

## 输出细节
- 金额、比例、折扣、下浮系数必须保留原文措辞，不得自行换算或补单位。
- 同一条款不得在“投标限价”和“折扣/下浮”重复出现；金额限价归入投标限价，比例下浮归入折扣/下浮。
- 多个标段共享同一限价类型时，在同一单元格内用 `<br>` 逐项列出。
- 禁止输出模板占位金额、空白金额、示例金额或“详见附件”类无效内容。
