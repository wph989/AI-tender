# 价格要求输出格式

下列 Markdown 只定义展示分类、列名和层级；实际通过工具提交 content JSON。
正文按全部证据综合，引用独立保存；无依据内容省略，未决事项登记为检索缺口。

```markdown
## 投标限价
| 限价类型 | 金额或范围（原文） | 超限处理 |
|----------|--------------------|----------|
|  |  |  |

## 价格构成
| 费用项 | 计算方式或比例（原文） |
|--------|------------------------|
|  |  |

## 折扣/下浮
| 下浮类型 | 范围或要求（原文） |
|----------|--------------------|
|  |  |
```

## 内容约束
- 金额、比例、折扣、下浮系数必须保留原文措辞，不得自行换算或补单位。
- 同一条款不得在“投标限价”和“折扣/下浮”重复出现；金额限价归入投标限价，比例下浮归入折扣/下浮。
- 多个标段共享同一限价类型时，在同一单元格内用 `<br>` 逐项列出。
- 禁止输出模板占位金额、空白金额、示例金额或“详见附件”类无效内容。
