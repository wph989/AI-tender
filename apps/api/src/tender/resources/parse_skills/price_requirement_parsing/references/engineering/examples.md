# 价格要求解析样例（工程类）

## 样例 1：工程量清单报价

### 输入原文
```
报价要求：
1. 本项目最高限价（招标控制价）为人民币58,600,000.00元（伍仟捌佰陆拾万元整），超过最高限价的投标将被否决
2. 报价方式：工程量清单计价，采用综合单价法
3. 投标人应按招标人提供的工程量清单逐项填报综合单价和合价，不得漏项
4. 暂列金额2,000,000.00元、暂估价1,500,000.00元，投标人应按给定金额计入报价，不得修改
5. 规费（社会保险费、住房公积金）和税金（增值税9%）为不可竞争费用，应按规定费率计算
6. 报价有效期：自投标截止日起120个日历天
```

### 期望输出
- 最高限价：58,600,000.00元（超限则废标）
- 报价方式：工程量清单计价 + 综合单价法
- 暂列金额：2,000,000.00元（不可修改）
- 暂估价：1,500,000.00元（不可修改）
- 不可竞争费：规费（社保+公积金）+ 税金（增值税9%）
- 报价有效期：120日历天
- 报价要求：逐项填报，不得漏项
