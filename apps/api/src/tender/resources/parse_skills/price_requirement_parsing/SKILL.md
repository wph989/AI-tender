# 价格要求解析 Skill

## 适用场景
- 触发：主 Agent 委派价格要求解析任务时调用。
- 输入：归一化 Markdown 文件，由运行时文件清单和受限工具提供。
- 输出：价格要求结构化文档（markdown 格式），直接作为最终回复返回，由父级代码统一入库。

## 领域知识

价格要求只回答“招标方如何约束本次投标报价”，主要包括：

1. **报价方式**：固定总价、单价合同、费率报价等
2. **最高限价/预算金额**：投标报价不得超过的上限
3. **报价包含内容**：税费、运费、安装费等是否包含
4. **折扣/下浮**：下浮率、折扣率、P 值范围
5. **超限处理**：超过限价或低于成本价的处理规则

每个金额、比例或税率都必须先判断主语：只有招标方设定的投标限价/预算、报价内部构成、下浮范围和超限处理可以提取。企业注册资本、营收、纳税、历史业绩金额，代理服务费、保证金、履约金、法规罚款、模板占位金额、历史成交价、市场参考价及纯价格评分公式必须排除。

## 识别规则

关键词种子（可扩展，不限于）："报价"、"价格"、"最高限价"、"预算金额"、"投标报价"、"费率"、"单价"、"总价"

## 执行流程

1. **精确检索**：使用 `grep` 搜索"报价""价格"等章节
2. **扩展上下文**：根据命中位置使用 `read_file` 读取报价表和相邻条款
3. **主语判定**：逐个判断候选数值是否约束本次投标报价
4. **逐列过滤**：混排表格只保留标段标识和限价、预算、报价构成、下浮相关列
5. **互斥归类**：金额限价、报价内部构成、折扣/下浮分别归表，不重复
6. **输出结果**：按规范格式生成完整 Markdown，直接作为最终回复返回，由父级代码统一入库

## 输出规范

- 输出格式已拆分到 `references/output_format.md`。
- 执行输出前必须读取并严格遵循该文件中的专属模板和输出细节。
- 命中规则时，结果正文只能包含按专属模板整理的实际价格要求，禁止附加解释性说明。
- 未命中任何约束本次投标报价的内容时，结果正文只能是 `无相关内容`，禁止补充主语判定、排除原因、检索过程或建议。

## 参考文件（按标类型加载）
根据当前项目的标类型（bid_type），加载对应子目录下的参考文件：
- `references/output_format.md`：本 Skill 专属输出模板和格式约束
- `references/<type_dir>/extraction_rules.md`：含税/不含税处理、报价方式分类、最高限价提取、严禁行为、自检清单
- `references/<type_dir>/examples.md`：完整报价要求提取样例
- bid_type 取值：service（服务类）、engineering（工程类）、goods（货物类）
- 如无法确定标类型，默认加载 service 目录

## 工具
- `grep`：在归一化 Markdown 中精确检索；具体路径、glob 和输出模式由运行时上下文与工具护栏约束
- `read_file`：围绕命中位置分页扩展读取上下文
- `list_extracted_files`：列出当前任务可用 Markdown 文件
- 无保存工具：模块结果直接作为最终回复返回，无相关内容也必须在最终回复正文中返回

## 注意
- 金额数字必须**精确提取**
- 注意区分"含税价"和"不含税价"
- 多标段同类限价在同一单元格用 `<br>` 逐项列出
- 模板占位符、“详见附件”“待定”等无实质数值内容不得输出
