# 价格要求解析 Skill

## 适用场景
- 触发：项目控制器启动当前专题价格要求解析任务时调用。
- 输入：授权资料清单与按需检索得到的原文块，不预先灌入全文。
- 输出：可增量暂存的 content JSON，block_ids 保留已读原文身份，整项审查后发布。

## 领域知识

价格要求只回答“招标方如何约束本次投标报价”，主要包括：

1. **报价方式**：固定总价、单价合同、费率报价等
2. **最高限价/预算金额**：投标报价不得超过的上限
3. **报价包含内容**：税费、运费、安装费等是否包含
4. **折扣/下浮**：下浮率、折扣率、P 值范围
5. **超限处理**：超过限价或低于成本价的处理规则

每个金额、比例或税率都必须先判断主语：只有招标方设定的投标限价/预算、报价内部构成、下浮范围和超限处理可以提取。企业注册资本、营收、纳税、历史业绩金额，代理服务费、保证金、履约金、法规罚款、模板占位金额、历史成交价、市场参考价及纯价格评分公式必须排除。

报价折扣率与评分基准系数可能使用相同字母（如K），须按原文定义区分。明确仅用于计算得分的公式、系数抽取和评分附件由评分专题核对，不继续作为报价专题的转引追踪或缺口；算术错误修正、异常低价说明及其否决条件仍属于报价约束，应保留全部触发条件和例外。

## 识别规则

可选定位线索（无需逐词查询）："报价"、"价格"、"最高限价"、"预算金额"、"投标报价"、"费率"、"单价"、"总价"

## 执行流程

1. **主题检索**：使用 `search_document_batch` 搜索"报价""价格"等章节
2. **扩展上下文**：根据命中位置使用 `read_document` 读取报价表和相邻条款
3. **主语判定**：逐个判断候选数值是否约束本次投标报价
4. **逐列过滤**：混排表格只保留标段标识和限价、预算、报价构成、下浮相关列
5. **互斥归类**：金额限价、报价内部构成、折扣/下浮分别归表，不重复
6. **输出结果**：按本 Skill 的输出协议调用 submit_analysis；没有依据的条目省略。

## 取证重点与完成判断

优先定位前附表、报价说明、报价表及价格附件，按连续条款读取；一次读取可解决多个核对项。
限价、计价方式、税费、报价范围及标段差异已核清后即可统一综合；尚缺内容明确到具体条款或材料再补查，缺失资料如实登记。

## 本项目的检索与输出

按 coverage.json 核对业务内容，保留范围、条件、例外及完整清单。研究与提交协议以运行时工具为准；本文件只定义本专题的业务判断。

运行时按阶段和当前工作提供规则；尚未提供的完整细则及示例可通过 read_file 按需查阅。

- `references/output_schema.json`：本项目机器格式声明，运行时从报告快照读取。
- `references/output_format.md`：事项组织、字段含义和实际 JSON 提交示例。
- `references/coverage.json`：本专题检索覆盖清单，未解决主题保留缺口。
- `references/<type_dir>/extraction_rules.md`：按实际品类加载的专题细则。
- `references/<type_dir>/examples.md`：模拟原文块与逐条提交样例。
type_dir 为 engineering、goods、service；只采用运行时明确的项目/标段品类，混合品类分别核对，不默认服务类。
