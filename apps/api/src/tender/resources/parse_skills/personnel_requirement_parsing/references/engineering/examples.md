# 人员要求解析样例（工程类）

## 样例 1：施工项目管理人员要求

### 输入原文
```
项目管理人员要求：
1. 项目经理：1名，具有建筑工程专业一级注册建造师执业资格，具有安全生产考核合格证（B证），具有10年及以上工程施工管理经验，近3年担任过至少1个单项合同金额不低于3000万元的类似工程项目经理
2. 技术负责人：1名，具有土木工程类高级技术职称，8年及以上工程施工管理经验
3. 安全员：不少于3名，均须持有有效的安全生产考核合格证（C证）
4. 施工员：不少于2名，持有施工员岗位证书
5. 质量员：不少于1名，持有质量员岗位证书
6. 上述人员均须提供近6个月在本单位缴纳的社会保险证明
7. 项目经理和安全员不得同时担任其他在建工程项目
```

**社保要求：** 全部人员提供近6个月本单位社保证明
