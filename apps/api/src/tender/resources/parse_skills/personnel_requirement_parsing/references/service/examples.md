# 人员要求解析样例

## 样例 1
### 输入原文
```
项目管理人员要求：
1. 项目经理：1名，具有建筑工程专业一级注册建造师执业资格，具有10年及以上工程施工管理经验，近3年担任过至少1个合同金额不低于2000万元的类似项目管理
2. 技术负责人：1名，具有工程类高级技术职称，8年及以上相关工作经验
3. 安全员：不少于2名，持有有效的安全生产考核合格证书（C证）
4. 上述人员均须提供近6个月在本单位缴纳的社会保险证明
5. 项目经理不得同时担任其他在建工程项目的项目经理
```

### 期望输出
| 岗位 | 人数 | 资质 | 经验 | 其他 |
|------|------|------|------|------|
| 项目经理 | 1 | 建筑工程专业一级建造师 | 10年+施工管理，近3年≥1个≥2000万类似项目 | 不得兼任其他在建项目 |
| 技术负责人 | 1 | 工程类高级职称 | 8年+ | |
| 安全员 | ≥2 | 安全生产考核C证 | | |
- 社保：全员近6个月本单位社保证明
