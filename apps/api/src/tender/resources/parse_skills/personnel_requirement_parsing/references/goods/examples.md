# 人员要求解析样例（货物类）

## 样例 1：设备采购项目人员要求

### 输入原文
```
项目团队要求：
1. 项目负责人：1名，具有机电类中级及以上技术职称，具有5年及以上相关设备供货项目管理经验
2. 安装调试工程师：不少于2名，具有同类空调设备的安装调试经验，持有特种作业操作证（电工作业）
3. 售后服务工程师：不少于2名，在项目所在地常驻，接到报修后2小时内到达现场
4. 培训讲师：不少于1名，具有3年及以上相关设备培训经验
5. 上述人员均须提供近3个月在本单位缴纳的社会保险证明
```
