# 项目基本信息提取规则

## 核心原则：精确提取，名称编号一字不改

---

## 一、识别与定位
### 常见位置：招标公告/招标文件首页、项目概况章节、投标人须知前附表
### 关键词种子（可扩展，不限于）："项目名称""招标编号""采购人""招标人""预算""资金来源""工期""采购方式"

## 二、精确提取规则
- 项目名称：**逐字复制**，不得缩写或省略
- 项目编号/招标编号：**逐字复制**，含所有前缀和符号
- 预算金额：精确到元，注意大写小写一致性校验
- 资金来源：财政资金/自筹/贷款/混合
- 采购方式：公开招标/邀请招标/竞争性谈判/竞争性磋商/单一来源/询价
- 工期/交货期：精确到日历天或具体日期
- 标段划分：如有，逐标段提取编号、名称、内容

## 三、严禁行为
- ❌ 缩写项目名称
- ❌ 修改编号格式
- ❌ 金额四舍五入
- ❌ 遗漏标段信息

## 四、自检清单
1. 项目名称与原文完全一致？2. 编号完整？3. 金额精确？4. 标段信息完整？
