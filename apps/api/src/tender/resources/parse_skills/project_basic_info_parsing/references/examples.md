# 项目基本信息解析样例

## 样例 1
### 输入原文
```
XX市2026年度城市道路维护工程（项目编号：ZFCG-2026-0315）
招标人：XX市城市管理局
招标代理机构：XX工程咨询有限公司
预算金额：人民币壹仟伍佰万元整（¥15,000,000.00元）
资金来源：市级财政拨款
采购方式：公开招标
本项目共分为2个标段：
  第一标段：城东片区道路维护，预算800万元
  第二标段：城西片区道路维护，预算700万元
工期：合同签订后365个日历天
```

| 项目编号 | ZFCG-2026-0315 |

标段：2个（城东800万+城西700万=1500万 ✓）
