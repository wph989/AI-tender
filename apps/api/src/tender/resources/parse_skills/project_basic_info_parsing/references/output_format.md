# 项目基本信息输出格式

下列 Markdown 只定义展示分类、列名和层级；实际通过工具提交 content JSON。
正文按全部证据综合，引用独立保存；无依据内容省略，未决事项登记为检索缺口。

## 内容约束
- 甲方信息、代理信息、项目基本信息之间禁止互相填充。
- 分标信息仅当原文明确出现标段/包明细时输出；没有分标时省略 `## 分标信息`。
- 多个分标的同一字段可在单元格内逐项列出，禁止写“同上”“详见分标信息”替代具体内容。
- 只保留有明确内容的字段；不得输出示例占位符或空表格行。
