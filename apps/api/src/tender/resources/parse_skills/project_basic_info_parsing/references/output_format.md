# 项目基本信息输出格式

## 通用返回要求
- 最终只发送一条普通 assistant 文本消息，内容为下述 Markdown 格式的结果正文。
- 正文前不得出现前言或代码围栏；正文必须是非空 Markdown，禁止空消息或只写“已完成”。
- 解析结论只输出项目基本信息相关内容，禁止混入评分、废标、技术方案等其他模块。
- 无明确来源的字段留空或省略，不得用其他主体信息互相填充。
- 全部无相关内容时，只输出 `无相关内容`。

## 甲方信息
| 字段 | 内容 |
|------|------|
| 公司名称 |  |
| 公司地址 |  |
| 公司联系人 |  |
| 公司联系电话 |  |
| 公司电子邮箱 |  |
| 公司开户银行 |  |
| 公司银行账号 |  |

## 代理信息

## 输出细节
- 甲方信息、代理信息、项目基本信息之间禁止互相填充。
- 分标信息仅当原文明确出现标段/包明细时输出；没有分标时省略 `## 分标信息`。
- 原文未明确的固定字段统一填写 `未提及`，但不得据其他主体或模板推断补全。
- 多个分标的同一字段可在单元格内逐项列出，禁止写“同上”“详见分标信息”替代具体内容。
- 只保留有明确内容的字段；不得输出示例占位符或空表格行。
