# 项目基本信息解析 Skill

## 适用场景
- 触发：主 Agent 委派项目基本信息解析任务时调用。
- 输入：归一化 Markdown 文件，由运行时文件清单和受限工具提供。
- 输出：项目基本信息结构化文档（markdown 格式），直接作为最终回复返回，由父级代码统一入库。

## 领域知识

项目基本信息是招标公告、文件首页、项目概况和投标人须知前附表中的事实信息，主要包括：

1. **项目名称**：招标项目全称
2. **项目编号**：招标编号/采购编号
3. **招标人**：采购人/招标人名称
4. **招标代理机构**：代理机构名称（如有）
5. **项目事实**：地点、规模、投标截止日期、服务期限、招标范围
6. **资金与限价**：最高投标限价、资金来源、资金落实情况
7. **标段信息**：标段/包名称与编号、资质、限额、中标人数量、负责人资质

合同范本、评分标准、投标文件格式模板、技术规范和资格审查条件中的示例或占位信息必须整体排除。甲方、代理和项目字段禁止互相填充。

## 识别规则

关键词种子（可扩展，不限于），按主体分组覆盖检索：
- **甲方/代理主体**："采购人"、"招标人"、"代理机构"、"联系人"、"联系电话"、"电子邮箱"、"开户银行"、"银行账号"、"地址"
- **项目事实**："项目名称"、"项目编号"、"招标编号"、"采购编号"、"项目地点"、"项目规模"、"投标截止"、"服务期限"、"工期"、"招标范围"
- **资金与限价**："预算金额"、"最高投标限价"、"最高限价"、"资金来源"、"资金落实"
- **标段/分标**："标段"、"包号"、"包名称"、"分标资质"、"分标限额"、"中标人数量"、"中标份额"、"项目负责人资质"

## 执行流程

1. **优先检索文件头部和关键字段**：使用 `grep` 搜索项目名称、招标编号、采购人等
2. **扩展上下文**：根据命中位置使用 `read_file` 读取前后内容
3. **排除伪来源**：跳过合同范本、评分、格式模板、技术规范及资格条件中的示例
4. **交叉核对**：按主体核对联系人和银行信息，按标段核对限价及中标份额
5. **输出结果**：按规范格式生成完整 Markdown，直接作为最终回复返回，由父级代码统一入库

## 输出规范

- 输出格式已拆分到 `references/output_format.md`。
- 执行输出前必须读取并严格遵循该文件中的专属模板和输出细节。
- 命中规则时，结果正文只能包含按专属模板整理的实际项目基本信息，禁止附加解释性说明。
- 未命中任何项目基本信息时，结果正文只能是 `无相关内容`，禁止补充未命中原因、检索过程或建议。

## 参考文件
- `references/output_format.md`：本 Skill 专属输出模板和格式约束
- `references/extraction_rules.md`：精确提取规则（名称逐字复制、编号格式、金额校验）、标段提取、严禁行为、自检清单
- `references/examples.md`：完整项目基本信息提取样例

## 工具
- `grep`：在归一化 Markdown 中精确检索；具体路径、glob 和输出模式由运行时上下文与工具护栏约束
- `read_file`：围绕命中位置分页扩展读取上下文
- `list_extracted_files`：列出当前任务可用 Markdown 文件
- 无保存工具：模块结果直接作为最终回复返回，无相关内容也必须在最终回复正文中返回

## 注意
- 项目基本信息通常位于文档**开头部分**，优先读取前 200 行
- 名称和编号必须**精确提取**，不得缩写或省略
- 如有标段划分，需完整提取各标段信息
- 注意区分"预算金额"和"最高限价"
- 分标限价同时写入项目最高投标限价和分标限额字段，不得用“同上”代替
