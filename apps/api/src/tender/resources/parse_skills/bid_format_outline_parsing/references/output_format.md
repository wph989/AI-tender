# 投标文件格式输出

采用树结构：每个逻辑标或独立材料为 kind=format_node，node_type=group/section。
title 保留原文名称，parent_key 引用已保存父节点；分组可以嵌套，逐条保存并保留全部章节层级与游离章节。
content 使用“编制要求”数组，综合填写需要编制的内容、材料清单、签章与附件要求。
每个节点有独立的实际原文引用；只按已核对的组织关系归类，不猜测缺失层级。
没有明确逻辑标时，独立材料作为根 section；不强制套用商务标、技术标等固定目录。
无对应格式时不生成空节点，检索范围与缺口通过 complete_research/coverage/gaps 记录。
