# 投标文件格式正文定位规则

## 任务

通读完整 DOCX，根据章节在文档中的实际功能，定位招标方规定投标文件组成、组织层次和具体材料格式的正文范围。

定位阶段产生内部 `start_element` 与 `end_element`，不提取章节树。最终回复只把
`end_element` 原值写入 `section_end_element_index`，用于服务端准确切分最后一个章节；
不得输出其他定位过程信息。

## 禁止机械定位

- 禁止搜索一组预设词后直接选择命中段落。
- 禁止要求章节标题必须采用某种名称或编号。
- 禁止根据文档前后位置、段落长短、页码或出现次数直接确定正文。
- 禁止把本文件中的示例当作完整名称列表。

章节标题可能明确，也可能含义宽泛；目标内容也可能拆散在多个连续章节中。应以章节实际承担的业务功能为准。

## 语义定位过程

### 1. 建立全文章节地图

分页阅读时持续理解：当前内容属于项目说明、投标规则、评审规则、合同约定、技术要求、投标材料格式，还是其他业务部分。记录章节之间的前后、包含和并列关系，不在第一次看到疑似标题时立即下结论。

### 2. 识别目标章节的实际功能

目标范围通常直接告诉投标人应提交哪些结构项，或者给出需要填写、签署、承诺、证明、报价、响应的具体材料形式。关键不是出现了什么词，而是这些内容是否共同回答“投标文件最终应怎样组织和编制”。

以下内容不是目标正文：

- 只是在其他条款中提到应按某处格式编制；
- 只说明装袋、密封或递交方式，但没有展开文件内部大纲；
- 只列出导航条目，没有展开任何实际模板或编制内容；
- 内容实质属于评审、合同或技术要求本身，而不是投标人提交材料的组织格式。

### 3. 区分目录与正文

不要根据单个外观特征判断。观察一组文本是否只起到指向后文的导航作用，还是已经开始给出可填写、可响应、可提交的实际内容。相同标题在目录和正文中可能重复出现，应选择承担实际规定功能的正文位置。

### 4. 确定完整边界

- 起点是目标业务功能真正开始的位置，可以包含该范围的根标题。
- 终点是最后一个仍在规定投标文件组织或材料格式的元素。
- 后续若切换到新的同级业务功能，目标范围在切换前结束。
- 若格式内容分成多个连续卷册或章节，应整体覆盖，不能只截取第一个部分。
- 对边界两侧重新精读，确认没有把前一章节的说明带入，也没有遗漏最后一组格式内容。

## 简单示例

- 某章标题很普通，但其后连续给出投标函、证明材料和响应文件的编制形式：应根据内容功能定位为目标正文。
- 目录中出现与正文相同的标题，但只列名称并指向后页：目录不是目标正文，后面真正展开材料要求的位置才是。
- 两个连续章节分别展开不同卷册的材料格式：两章共同构成完整目标范围。

示例只说明判断思路，不限定标题名称、材料名称或章节数量。
