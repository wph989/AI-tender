# 格式正文定位规则

定位规定投标文件组成、组织层次、填写或签署材料的正文范围。按材料名称与编制要求自主检索相关来源，根据命中位置扩展阅读，核对格式附件与补充通知。

不要仅按固定标题、编号、页码、文档位置或出现次数定位。目标章节可以名称宽泛，也可分散在多个章节或附件中，按是否实际规定投标人怎样组织和编制材料判断。

- 给出填写、签署、承诺、报价、证明或响应的具体材料形式，是格式正文。
- 仅说“按某处格式编制”是指引，需进一步阅读被指向的正文。
- 仅说明密封递交且不展开内部大纲，属于封装模块。
- 只提供标题导航、后文还有实际展开的区域是目录。
- 明确列出应提交的具体材料，也能形成材料清单；但不能凭一句分类罗列臆造逻辑标容器。

起点是格式业务真正开始的块，终点是最后一个仍规定组织或材料格式的块。在新的同级业务开始前结束。
多个附件分别保留来源，不能按ID大小推断跨文件的先后或归属。重新精读边界两侧，防止仅提取第一个格式或漏掉末尾附件。
边界只控制阅读，最终各节点通过实际 block_id 与连续引文溯源。
