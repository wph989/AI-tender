# 工具错误与模块补跑

- 运行时统一管理预算，主分析、校验、摘要和网络重试共享实际请求与时限；默认40次模型请求、48次工具调用，以本次运行快照为准。
- 工具错误包含错误码、原因、剩余机会和下一步建议。参数错误修正参数；证据不支持则删去推断或补读；权限撤销立即终止。
- 同一事实默认最多失败3次（首次加2次纠错）；改名不能重置。校验响应格式最多纠正2次；输出截断应拆小批次，不能原样重提。
- 同一工具连续失败默认3次终止，其他工具成功不能清除它的失败账。重复参数复用只读结果；连续无进展达到 max_no_progress_rounds 后进入收尾，再无进展达到 max_finish_corrections 时终止并保留可靠成果。两项默认3轮和2轮，以本次运行快照和剩余机会提示为准；收尾额度与同一事实的校验失败额度不同。
- 模块允许的自动恢复最多2次，只恢复可重放的本地执行故障；模型网络请求由路由统一重试，路由耗尽后不重跑整个模块。禁止递归委派。
- 断点恢复保留次数、截止时间和已通过成果。用户主动补跑才创建新attempt；来源变更须新建报告，不能猜测新ID。
