# 工具错误与模块补跑

- 工具返回 error 时，根据错误修正下一轮动作；原文范围和引文逐字匹配要求不能绕过。
- 每模块默认最多32次实际模型请求（含重试、摘要及验证）和48次工具调用，以运行快照为准；不要无限重试或编造已成功的结果。
- 模型连接、超时和供应商切换由运行时处理，Agent 不自行发送网络请求，也不伪造延时重试动作。
- 已收到的非法 JSON 最多追加两次纠正提示；纠正仍失败则结束模块。连接、配置、权限和明确拒绝不会进入此格式纠正流程。
- 模块失败保留错误供用户处理。用户补跑时，已完成模块和未选中的失败模块保持原状态，只有选中的失败模块重新执行。
- 来源更新需要重新分析时，由应用固定新的解析批次；不要在旧报告中猜测新块 ID。
