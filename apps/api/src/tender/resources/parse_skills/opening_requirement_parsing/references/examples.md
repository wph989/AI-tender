# 开标要求解析样例

## 样例 1：标准开标信息

### 输入原文
```
五、投标文件递交及开标
1. 投标文件递交截止时间：2026年3月15日上午9时30分（北京时间）
2. 投标文件递交地点：XX市公共资源交易中心三楼第二开标室（XX市XX路168号）
3. 开标时间：2026年3月15日上午9时30分
4. 开标地点：同投标文件递交地点
5. 投标人应派法定代表人或其授权代表携带有效身份证件准时参加开标会议
```

### 期望输出
- 投标截止：2026年3月15日 09:30（北京时间）
- 开标时间：同上（与投标截止一致）
- 地点：XX市XX路168号，XX市公共资源交易中心三楼第二开标室
- 参与人：法定代表人或授权代表 + 有效身份证件

## 样例 2：远程开标

### 输入原文
```
本项目采用全流程电子化交易，实行远程不见面开标。
开标时间：2026年4月1日10:00
投标人须在开标前通过XX电子招投标系统完成投标文件的上传和解密。
CA数字证书需在有效期内。
```

### 期望输出
- 开标方式：远程不见面开标（全流程电子化）
- 开标时间：2026年4月1日 10:00
- 特殊要求：通过XX系统上传+解密、CA数字证书需在有效期内
