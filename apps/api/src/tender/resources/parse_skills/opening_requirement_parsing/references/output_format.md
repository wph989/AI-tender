# 开标要求输出格式

下列 Markdown 只定义展示分类、列名和层级；实际通过工具提交 content JSON。
正文按全部证据综合，引用独立保存；无依据内容省略，未决事项登记为检索缺口。

```markdown
## 开标时间
| 时间要素 | 具体要求 |
|----------|----------|
|  |  |

## 开标地点
| 地点要素 | 具体要求 |
|----------|----------|
|  |  |

## 开标方式
| 方式类型 | 具体要求 |
|----------|----------|
|  |  |

## 参与人员要求
| 人员类型 | 具体要求 |
|----------|----------|
|  |  |

## 开标程序
| 程序步骤 | 具体要求 |
|----------|----------|
|  |  |

## 公开程度
| 公开要素 | 具体要求 |
|----------|----------|
|  |  |

## 其他开标相关要求
| 要求类型 | 具体内容 |
|----------|----------|
|  |  |
```

## 内容约束
- 时间、地点必须按原文精确输出，不得自行换算日期或推断地点。
- 投标截止时间如果与开标时间有关联，应放入 `## 开标时间`，并保留原文关系描述。
- 线上/远程/不见面开标要求放入 `## 开标方式`，登录平台、解密时限等可写入同一分类。
- 开标携带材料属于参与开标要求时，放入 `## 参与人员要求` 或 `## 其他开标相关要求`，不要另起无关分类。
