# 开标要求输出格式

## 通用返回要求
- 最终只发送一条普通 assistant 文本消息，内容为下述 Markdown 格式的结果正文。
- 正文前不得出现前言或代码围栏；正文必须是非空 Markdown，禁止空消息或只写“已完成”。
- 解析结论只输出开标时间、地点、方式、参与人员、开标程序、公开程度和其他开标相关要求。
- 无对应内容的分类整段省略；全部无相关内容时，只输出 `无相关内容`。

```markdown

## 开标时间
| 时间要素 | 具体要求 |
|----------|----------|
|  |  |

## 开标地点
| 地点要素 | 具体要求 |
|----------|----------|
|  |  |

## 开标方式
| 方式类型 | 具体要求 |
|----------|----------|
|  |  |

## 参与人员要求
| 人员类型 | 具体要求 |
|----------|----------|
|  |  |

## 开标程序
| 程序步骤 | 具体要求 |
|----------|----------|
|  |  |

## 公开程度
| 公开要素 | 具体要求 |
|----------|----------|
|  |  |

## 其他开标相关要求
| 要求类型 | 具体内容 |
|----------|----------|
|  |  |
```

## 输出细节
- 时间、地点必须按原文精确输出，不得自行换算日期或推断地点。
- 投标截止时间如果与开标时间有关联，应放入 `## 开标时间`，并保留原文关系描述。
- 线上/远程/不见面开标要求放入 `## 开标方式`，登录平台、解密时限等可写入同一分类。
- 开标携带材料属于参与开标要求时，放入 `## 参与人员要求` 或 `## 其他开标相关要求`，不要另起无关分类。
