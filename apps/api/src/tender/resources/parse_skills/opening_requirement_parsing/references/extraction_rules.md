# 开标要求提取细则

以下内容是检索和判断指导，示例名词不代表本项目事实。只使用本次已读原文作依据。

检索公告、投标人须知、开标安排及变更通知，区分投标截止、开标、签到与解密时间。
- 日期、时刻、时区、地址和会议室保留原文已有精度；缺年月日或分钟不补齐，远程地址不推导为现场地点。
- 投标截止与开标同一时刻只有原文明示才能关联，变更须引用原安排及通知。
- 远程开标保留平台、登录、签到、解密时限、故障处理和授权代表要求，不能套用线下流程。
- 参与者身份、授权文件、携带材料及公开安排按具体事项记录；未提到法定代表人必须到场时不推定。
- 操作流程中的条件分支和超时后果完整保留，无关的文件格式和后续评标评分不收录。
