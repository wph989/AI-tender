# 开标要求解析 Skill

## 适用场景
- 触发：主 Agent 委派开标要求解析任务时调用。
- 输入：归一化 Markdown 文件，由运行时文件清单和受限工具提供。
- 输出：开标要求结构化文档（markdown 格式），直接作为最终回复返回，由父级代码统一入库。

## 领域知识

开标要求是招标文件中规定开标仪式相关事项的内容，主要包括：

1. **开标时间**：具体日期和时刻
2. **开标地点**：详细地址、楼层、会议室
3. **参与人员**：投标人需派出的代表（法定代表人/授权代表）
4. **携带材料**：开标时需携带的证件、文件
5. **开标流程**：唱标顺序、确认签字等环节
6. **开标方式**：现场、线上、远程或不见面开标
7. **公开程度**：公开范围、见证人员及其他公开要求
8. **其他要求**：解密时限、迟到处理等开标相关规定

## 识别规则

关键词种子（可扩展，不限于）："开标"、"开标时间"、"开标地点"、"投标截止"、"递交截止"、"开标仪式"

## 执行流程

1. **精确检索**：使用 `grep` 搜索"开标""投标截止"等章节
2. **扩展上下文**：根据命中位置使用 `read_file` 读取相邻条款
3. **提取信息**：提取时间、地点、方式、人员、程序、公开程度及其他要求
4. **输出结果**：按规范格式生成完整 Markdown，直接作为最终回复返回，由父级代码统一入库

## 输出规范

- 输出格式已拆分到 `references/output_format.md`。
- 执行输出前必须读取并严格遵循该文件中的专属模板和输出细节。
- 命中规则时，结果正文只能包含按专属模板整理的实际解析结果，禁止附加解释性说明。
- 未命中任何开标要求时，结果正文只能是 `无相关内容`，禁止补充未命中原因、检索过程或建议。

## 参考文件
- `references/output_format.md`：本 Skill 专属输出模板和格式约束
- `references/extraction_rules.md`：时间/地点精确提取规则、远程开标处理、严禁行为、自检清单
- `references/examples.md`：标准开标、远程开标样例

## 工具
- `grep`：在归一化 Markdown 中精确检索；具体路径、glob 和输出模式由运行时上下文与工具护栏约束
- `read_file`：围绕命中位置分页扩展读取上下文
- `list_extracted_files`：列出当前任务可用 Markdown 文件
- 无保存工具：模块结果直接作为最终回复返回，无相关内容也必须在最终回复正文中返回

## 注意
- 时间和地点信息必须**精确提取**，不得推断或猜测
- 注意区分"投标截止时间"和"开标时间"
- 注意是否有"远程开标""线上开标"等特殊安排
- 无实质内容的类别整段省略，不输出空表格
