# 开标要求解析 Skill

## 适用场景
- 触发：项目控制器启动当前专题开标要求解析任务时调用。
- 输入：授权资料清单与按需检索得到的原文块，不预先灌入全文。
- 输出：研究结束后统一综合的 content JSON，逐条附独立的原文溯源引用。

## 领域知识

开标要求是招标文件中规定开标仪式相关事项的内容，主要包括：

1. **开标时间**：具体日期和时刻
2. **开标地点**：详细地址、楼层、会议室
3. **参与人员**：投标人需派出的代表（法定代表人/授权代表）
4. **携带材料**：开标时需携带的证件、文件
5. **开标流程**：唱标顺序、确认签字等环节
6. **开标方式**：现场、线上、远程或不见面开标
7. **公开程度**：公开范围、见证人员及其他公开要求
8. **其他要求**：解密时限、迟到处理等开标相关规定

## 识别规则

关键词种子（可扩展，不限于）："开标"、"开标时间"、"开标地点"、"投标截止"、"递交截止"、"开标仪式"

## 执行流程

1. **主题检索**：使用 `search_document` 搜索"开标""投标截止"等章节
2. **扩展上下文**：根据命中位置使用 `read_document` 读取相邻条款
3. **提取信息**：提取时间、地点、方式、人员、程序、公开程度及其他要求
4. **输出结果**：按本 Skill 的输出协议调用 submit_analysis；没有依据的条目省略。

## 本项目的检索与输出

按 coverage.json 核对业务内容，保留范围、条件、例外及完整清单。研究与提交协议以运行时工具为准；本文件只定义本专题的业务判断。

- `references/output_format.md`：事项组织、字段含义和实际 JSON 提交示例。
- `references/coverage.json`：本专题检索覆盖清单，未解决主题保留缺口。
