# 废标项解析样例

## 样例 1：资格审查表中的废标项

### 输入原文
```
第三章 评标办法
一、资格审查
评标委员会对投标人进行资格审查，审查内容如下：
1. 投标人应具有独立的法人资格，持有有效的营业执照
2. 投标人应具有建筑工程施工总承包二级及以上资质
3. 投标人应具有有效的安全生产许可证
4. 项目经理应具有建筑工程专业二级及以上注册建造师执业资格
5. 投标人未被列入失信被执行人名单
6. 投标人近三年内无行贿犯罪记录
未通过资格审查的投标人，其投标将被否决。
```

### 期望输出
```markdown
## <span style="color:#d32f2f">主体资格类</span>
| 废标情形 | 具体描述 |
|----------|----------|
| 未具有独立法人资格或未持有有效营业执照 | 投标人应具有独立法人资格并持有有效营业执照；未通过资格审查的投标将被否决。 |
| 未具有建筑工程施工总承包二级及以上资质 | 投标人应具有建筑工程施工总承包二级及以上资质；未通过资格审查的投标将被否决。 |
| 未具有有效的安全生产许可证 | 投标人应具有有效的安全生产许可证；未通过资格审查的投标将被否决。 |
| 项目经理未具有建筑工程专业二级及以上注册建造师执业资格 | 项目经理应具有建筑工程专业二级及以上注册建造师执业资格；未通过资格审查的投标将被否决。 |

## 违法违规类
| 废标情形 | 具体描述 |
|----------|----------|
| 投标人被列入失信被执行人名单 | 投标人未被列入失信被执行人名单；未通过资格审查的投标将被否决。 |
| 投标人近三年内存在行贿犯罪记录 | 投标人近三年内无行贿犯罪记录；未通过资格审查的投标将被否决。 |
```

禁止简化为“未通过资格审查的投标将被否决”一条；该句只证明前述6项均具有否决效力。

## 样例 2：评分表中隐藏的废标项

### 输入原文
```
二、初步评审
| 序号 | 评审内容 | 评审标准 | 是否合格 |
|------|---------|---------|---------|
| 1 | 投标文件签署 | 法定代表人或授权代表签字并加盖公章 | 合格/不合格 |
| 2 | 投标保证金 | 按规定缴纳投标保证金 | 合格/不合格 |
| 3 | 投标有效期 | 不少于90天 | 合格/不合格 |
| 4 | 投标报价 | 不超过最高限价2000万元 | 合格/不合格 |
```

### 期望输出
本片段没有明确“不合格即否决”的后果，本模块不输出这4项。继续阅读初步评审总则；只有找到明确的否决关联后，才逐项输出签署、保证金、有效期和限价门槛，同时引用后果依据。“合格/不合格”栏目本身不足以证明废标。

## 样例 3：区分废标项和评分项

### 输入原文
```
投标人具有ISO9001质量管理体系认证的，得2分，不提供的不得分。
投标人未提供投标保证金的，其投标将被否决。
```

### 期望输出
- ✅ 提取："未提供投标保证金 → 投标被否决"（废标项，保证金类）
- ❌ 不提取："具有ISO9001认证得2分"（这是评分项，不是废标项）

## 样例 4：兜底条款

### 输入原文
```
出现以下情形之一的，投标无效：
（一）投标文件未按要求密封的；
（二）投标文件未加盖投标人公章的；
（三）其他不符合招标文件实质性要求的。
```

### 期望输出
提取3条，其中第3条应标注为"兜底条款"：
```
| 3 | 其他不符合招标文件实质性要求的情形 | 其他 | "其他不符合招标文件实质性要求的"（兜底条款） |
```
