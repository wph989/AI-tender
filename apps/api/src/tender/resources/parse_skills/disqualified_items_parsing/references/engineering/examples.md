# 废标项解析样例（工程类）

## 样例 1：施工招标资格审查

### 输入原文
```
第三章 评标办法
一、资格审查
1. 投标人应具有建筑工程施工总承包二级及以上资质
2. 投标人应具有有效的安全生产许可证
3. 拟派项目经理应具有建筑工程专业二级及以上注册建造师执业资格，并具有安全生产考核合格证（B证）
4. 投标人近3年（2023年1月至今）应完成至少1个单项合同金额不低于1000万元的类似工程施工业绩
5. 投标人应提供2023年度经审计的财务报告
6. 拟派项目经理不得有其他在建工程
未通过资格审查的投标人，其投标将被否决。
```

### 期望输出
| 序号 | 废标条件 | 类型 | 原文引用 |
|------|---------|------|---------|
| 1 | 建筑工程施工总承包二级及以上资质 | 资质类 | "具有建筑工程施工总承包二级及以上资质" |
| 2 | 有效的安全生产许可证 | 资质类 | "具有有效的安全生产许可证" |
| 3 | 建筑工程专业二级及以上注册建造师 + B证 | 人员类 | "具有建筑工程专业二级及以上注册建造师执业资格，并具有安全生产考核合格证（B证）" |
| 4 | 近3年至少1个≥1000万元类似工程施工业绩 | 业绩类 | "近3年（2023年1月至今）应完成至少1个单项合同金额不低于1000万元的类似工程施工业绩" |
| 5 | 2023年度经审计的财务报告 | 财务类 | "提供2023年度经审计的财务报告" |
| 6 | 项目经理无在建工程 | 人员类 | "拟派项目经理不得有其他在建工程" |

禁止把上述6项合并为“不满足工程类资格审查条件将被否决”；必须保留每项的资质等级、证书、人员、业绩和财务限定。

## 样例 2：评分表中的隐性废标项

### 输入原文
```
初步评审标准：
| 序号 | 审查内容 | 审查标准 | 备注 |
|------|---------|---------|------|
| 1 | 投标文件签署 | 法定代表人或其授权代表签字并加盖公章 | 不满足则否决 |
| 2 | 投标报价 | 不超过最高限价3500万元 | 超限则否决 |
| 3 | 工期 | 不超过招标文件规定的365日历天 | 超限则否决 |
| 4 | ★技术方案 | 满足招标文件实质性技术要求 | 不满足则否决 |
```

### 期望输出
注意：虽然位于"评分表"中，但"不满足则否决"的条款是废标项：
| 序号 | 废标条件 | 类型 | 原文引用 |
|------|---------|------|---------|
| 1 | 签字并盖章 | 形式类 | "法定代表人或其授权代表签字并加盖公章" |
| 2 | 报价不超过3500万元 | 价格类 | "不超过最高限价3500万元" |
| 3 | 工期不超过365日历天 | 工期类 | "不超过招标文件规定的365日历天" |
| 4 | ★技术方案满足实质性要求 | 技术类 | "满足招标文件实质性技术要求" |
