# 废标项解析样例（货物类）

## 样例 1：设备采购资格审查

### 输入原文
```
第二章 投标人资格要求
1. 投标人应为在中华人民共和国境内注册的独立法人
2. 投标产品应具有有效的CCC强制性产品认证证书
3. 投标产品应提供国家认可的第三方检测机构出具的近1年内的检测合格报告
4. 代理商投标的，应提供制造商针对本项目的授权函（不接受二级代理授权）
5. 投标人应具有ISO9001质量管理体系认证证书
6. 投标产品交货期不超过合同签订后60个日历天，否则投标将被否决
```

### 期望输出
| 序号 | 废标条件 | 类型 | 原文引用 |
|------|---------|------|---------|
| 1 | 有效的CCC认证证书 | 产品认证类 | "投标产品应具有有效的CCC强制性产品认证证书" |
| 2 | 近1年内第三方检测合格报告 | 产品认证类 | "国家认可的第三方检测机构出具的近1年内的检测合格报告" |
| 3 | 制造商针对本项目的授权函 | 供应商资质类 | "制造商针对本项目的授权函（不接受二级代理授权）" |
| 4 | ISO9001质量管理体系认证 | 供应商资质类 | "应具有ISO9001质量管理体系认证证书" |
| 5 | 交货期≤60日历天 | 交货类 | "交货期不超过合同签订后60个日历天，否则投标将被否决" |

禁止把供应商资质和产品准入要求合并为“不满足资格条件将导致废标”；必须逐项保留认证名称、报告类型及时效、授权范围等限定。

## 样例 2：含样品要求的废标项

### 输入原文
```
评审要求：
1. ★产品制冷量≥50kW，不满足则投标无效
2. ★产品能效等级不低于一级
3. 投标人须随投标文件提交产品样机1台，未提交样机或样机检测不合格的，其投标将被否决
4. 质保期不少于3年，低于3年的投标无效
```

### 期望输出
| 序号 | 废标条件 | 类型 | 原文引用 |
|------|---------|------|---------|
| 1 | 制冷量≥50kW | 技术参数类 | "★产品制冷量≥50kW，不满足则投标无效" |
| 2 | 能效等级≥一级 | 技术参数类 | "★产品能效等级不低于一级" |
| 3 | 提交产品样机1台且检测合格 | 样品类 | "提交产品样机1台，未提交样机或样机检测不合格的，其投标将被否决" |
| 4 | 质保期≥3年 | 售后类 | "质保期不少于3年，低于3年的投标无效" |
