# 废标项解析样例（货物类）

## 样例 1：设备采购资格审查

### 输入原文
```
第二章 投标人资格要求
1. 投标人应为在中华人民共和国境内注册的独立法人
2. 投标产品应具有有效的CCC强制性产品认证证书
3. 投标产品应提供国家认可的第三方检测机构出具的近1年内的检测合格报告
4. 代理商投标的，应提供制造商针对本项目的授权函（不接受二级代理授权）
5. 投标人应具有ISO9001质量管理体系认证证书
6. 投标产品交货期不超过合同签订后60个日历天，否则投标将被否决
```

### 期望输出
| 序号 | 废标条件 | 类型 | 原文引用 |
|------|---------|------|---------|
| 1 | 交货期超过合同签订后60个日历天将被否决 | 实质性响应类 | "投标产品交货期不超过合同签订后60个日历天，否则投标将被否决" |

本例只对交货期明示否决后果，不能由“资格要求”标题或“应”字推断前五项的否决效力。如果其他已读条款明确把资格清单与否决相连，才逐项补充，并同时引用每个门槛和否决后果。

## 样例 2：含样品要求的废标项

### 输入原文
```
评审要求：
1. ★产品制冷量≥50kW，不满足则投标无效
2. ★产品能效等级不低于一级
3. 投标人须随投标文件提交产品样机1台，未提交样机或样机检测不合格的，其投标将被否决
4. 质保期不少于3年，低于3年的投标无效
```

### 期望输出
| 序号 | 废标条件 | 类型 | 原文引用 |
|------|---------|------|---------|
| 1 | 制冷量≥50kW | 技术参数类 | "★产品制冷量≥50kW，不满足则投标无效" |
| 2 | 提交产品样机1台且检测合格 | 样品类 | "提交产品样机1台，未提交样机或样机检测不合格的，其投标将被否决" |
| 3 | 质保期≥3年 | 售后类 | "质保期不少于3年，低于3年的投标无效" |

能效条款只有星号和强制要求，未给出星号代表否决的规则，本模块不推断其为废标条件。
