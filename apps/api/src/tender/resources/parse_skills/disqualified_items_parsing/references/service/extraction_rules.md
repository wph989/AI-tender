# 废标项提取规则

## 核心原则：完整提取，不得遗漏任何废标/否决条件

废标项是投标的**生死线**——漏掉一条废标项可能导致投标人因忽略关键要求而被否决。
本模块优先保证**高召回率**，宁可多提取疑似废标项，也不得遗漏。

---

## 一、废标项的定义与识别

### 1.1 什么是废标项

废标项（否决投标条款、投标无效情形）是招标文件中的**强制性条款**，投标人违反任何一条都将导致投标被否决。
与评分项（加分/扣分）有本质区别：废标项是**门槛**，评分项是**竞争**。

### 1.2 废标项在文档中的常见位置

按优先级搜索以下章节：
1. **"资格审查"或"初步评审"章节** — 最集中、最完整的废标条件
2. **"废标条款"或"否决投标"专章** — 如有此章节，围绕该章节行号范围完整提取
3. **"评标办法"章节** — 评标办法表格中的"审查标准"列通常包含废标条件
4. **"投标人须知"章节** — 散落在各条款中的强制性要求
5. **"投标文件格式"章节** — 格式不符即废标的隐含条件
6. **全文件其他位置** — 用"必须""应当""不得"等关键词兜底搜索，再围绕命中位置扩展上下文

### 1.3 关键词种子清单

**一级关键词（高置信度，必须搜索）：**
- "废标""否决投标""投标无效""不予受理""驳回投标"
- "资格审查不通过""初步评审不合格"

**二级关键词（中置信度，辅助搜索）：**
- "必须""应当""不得""否则""否则按废标处理"
- "未提供""未提交""未缴纳""未密封""未签字""未盖章"
- "有下列情形之一的""出现下列情况之一的"

**三级关键词（低置信度，补充搜索）：**
- "强制性要求""实质性要求""关键参数""★标记"
- "最高限价""预算金额""超过则废标"

### 1.4 资格清单与后置否决结论

- 资格审查章节常先列出营业执照、资质、人员、业绩、财务和信用条件，最后统一说明“未通过资格审查的投标将被否决”。
- 末尾结论使前述每一项都具备否决效力；必须回读完整列表并逐项输出，禁止只提取末尾结论。
- “资格审查不通过”“不满足资格条件”等概括句不是可执行明细，不得作为主体资格类的唯一一行。
- 复合条款包含多个可独立判定条件时必须拆分；同一证件的名称、等级和有效期属于一个完整条件，不得拆散后丢失限定词。

## 二、分类规则

将每条废标条件归入以下类型之一：

| 类型编码 | 类型名称 | 典型内容 |
|---------|---------|---------|
| QUALIFICATION | 资格条件类 | 资质等级、营业执照、安全生产许可、联合体限制 |
| TECHNICAL | 技术要求类 | 关键参数不达标（★参数）、技术方案缺失 |
| COMMERCIAL | 商务要求类 | 投标有效期不足、报价超限、工期不满足 |
| FORMAT | 格式要求类 | 密封不符、签章缺失、份数不足、装订不符 |
| LEGAL | 法律法规类 | 关联关系、黑名单、行贿记录、失信被执行人 |
| DEPOSIT | 保证金类 | 未缴纳保证金、金额不足、方式不符、截止时间 |
| OTHER | 其他 | 无法归入上述类型的废标条件 |

## 三、严禁行为

以下行为**视为错误**：

- ❌ 将评分项（加分/扣分项）误识别为废标项
  - 判断标准：如果违反该条件只是**扣分**而非**否决投标**，则它是评分项
- ❌ 将建议性要求误识别为废标项
  - "建议""宜""可""鼓励"等表述不是强制性要求
- ❌ 遗漏"隐含废标项"
  - 有些废标条件不直接写"废标"，而是写"必须满足XX要求"，违反即为废标
- ❌ 合并多条独立的废标条件为一条
  - 每条废标条件应独立成项，不得合并
- ❌ 用资格审查概括句代替具体资格要求
  - 必须展开营业执照、资质等级、人员资格、业绩、财务、信用等原文明细
- ❌ 改写原文内容
  - 废标条件描述应**引用原文**，不得概括或改写
- ❌ 忽略表格中的废标条件
  - 评标办法表格中"是否合格""审查标准"列通常包含废标条件

## 四、边界案例处理

### 4.1 模糊表述
- "其他不符合招标文件实质性要求的情形" — 需单独提取并标注为"兜底条款"
- "招标人认为不满足要求的" — 需提取并标注"主观判断类"

### 4.2 条件性废标
- "如招标文件要求提供原件而未提供的" — 需提取，标注触发条件
- "未在截止时间前送达的" — 需提取，关联开标时间

### 4.3 分散在多处的废标条件
- 同一个废标条件可能在"投标人须知""评标办法""资格要求"中重复出现
- 去重规则：语义相同的条件只保留一条，标注所有出现位置

### 4.4 评分表中的废标项
- 评标办法的"初步评审"或"资格审查"表格中，每个"合格/不合格"项都是废标项
- 必须完整提取表格中的每一行

## 五、自检清单

输出前逐项检查：
1. **完整性**：是否覆盖了"资格审查""初步评审""评标办法"中的所有废标条件？
2. **独立性**：每条废标条件是否独立成项，未合并多条？
3. **原文引用**：每条是否附带了原文引用？
4. **分类正确**：每条的类型编码是否准确？
5. **区分废标/评分**：是否误将评分项混入废标项？
6. **兜底条款**：如有"其他不符合"类条款，是否已单独标注？
7. **资格展开**：主体资格类是否逐项包含具体门槛，且没有“详见资格要求”等概括项？
