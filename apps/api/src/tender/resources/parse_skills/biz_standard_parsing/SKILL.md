# 商务标准解析 Skill

## 适用场景
- 触发：主 Agent 委派商务标准解析任务时调用。
- 输入：归一化 Markdown 文件，由运行时文件清单和受限工具提供。
- 输出：商务标准结构化列表（markdown 格式），直接作为最终回复返回，由父级代码统一入库。

## 领域知识

商务标准回答“如何交易、如何履约”，仅包括：付款、交付、商务验收、质保与售后、违约责任、保险与担保、知识产权与保密、争议解决、合同变更与终止。

以下内容由其他模块处理，必须排除：技术规格和功能参数、企业资格和业绩、人员要求、评分细则、投标文件格式、报价构成及项目概况。投标保证金和履约保证金统一由保证金要求模块处理，商务标准不得重复提取。

## 识别规则

以下为关键词种子和重点章节名；应根据文档措辞继续扩展同义词：
- "商务要求"、"合同条款"、"付款"、"交付"、"验收"
- "质保"、"售后"、"违约"、"保险"
- "知识产权"、"保密"、"争议解决"、"仲裁"、"不可抗力"

## 执行流程

1. **精确检索**：使用 `grep` 搜索商务要求、合同条款及九类履约主题
2. **扩展上下文**：根据命中位置使用 `read_file` 读取相邻条款
3. **边界判断**：确认条款约束合同交易或履约，而非资格、评分、技术或报价
4. **分类整理**：同一条款只归入最相关的一类，保留期限、比例、条件和责任
5. **输出结果**：按规范格式生成完整 Markdown，直接作为最终回复返回，由父级代码统一入库

## 输出规范

- 输出格式已拆分到 `references/output_format.md`。
- 执行输出前必须读取并严格遵循该文件中的专属模板和输出细节。
- 命中规则时，结果正文只能包含按专属模板整理的实际解析结果，禁止附加解释性说明。
- 未命中任何商务标准时，结果正文只能是 `无相关内容`，禁止补充未命中原因、检索过程或建议。

## 参考文件
- `references/output_format.md`：本 Skill 专属输出模板和格式约束

## 工具
- `grep`：在归一化 Markdown 中精确检索；具体路径、glob 和输出模式由运行时上下文与工具护栏约束
- `read_file`：围绕命中位置分页扩展读取上下文
- `list_extracted_files`：列出当前任务可用 Markdown 文件
- 无保存工具：模块结果直接作为最终回复返回，无相关内容也必须在最终回复正文中返回

## 注意
- 商务验收只提取流程、期限、主体和付款关联，不展开具体技术指标
- 不得把评分表中的商务得分项当作商务履约条款
- 禁止输出推断结论或“待确认”，只输出原文能够支持的要求
