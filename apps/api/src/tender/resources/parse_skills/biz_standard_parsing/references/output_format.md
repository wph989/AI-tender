# 商务标准输出格式

## 通用返回要求
- 最终只发送一条普通 assistant 文本消息，内容为下述 Markdown 格式的结果正文。
- 正文前不得出现前言或代码围栏；正文必须是非空 Markdown，禁止空消息或只写“已完成”。
- 解析结论只输出商务标准和合同履约类要求，禁止混入人员、企业业绩、评分细则和废标项的专属内容。
- 无对应内容的分类整段省略；全部无相关内容时，只输出 `无相关内容`。

```markdown

## 付款条件
| 付款要素 | 具体要求 |
|----------|----------|
|  |  |

## 交付要求
| 交付要素 | 具体要求 |
|----------|----------|
|  |  |

## 验收条款
| 验收要素 | 具体要求 |
|----------|----------|
|  |  |

## 质保与售后服务
| 服务要素 | 具体要求 |
|----------|----------|
|  |  |

## 违约责任
| 违约情形 | 责任内容 |
|----------|----------|
|  |  |

## 保险与担保要求
| 担保类型 | 具体要求 |
|----------|----------|
|  |  |

## 知识产权与保密
| 条款类型 | 具体要求 |
|----------|----------|
|  |  |

## 争议解决
| 解决方式 | 具体内容 |
|----------|----------|
|  |  |

## 合同变更与终止
| 条款类型 | 具体要求 |
|----------|----------|
|  |  |
```

## 输出细节
- 同一内容只归入最相关的一个商务分类，避免重复。
- 付款、交付、验收、质保、违约等条款优先保留原文完整表述，不得简化关键期限、比例、条件。
- 如果条款实际属于人员、业绩、废标或评分模块，直接排除，不写入解析结论。
