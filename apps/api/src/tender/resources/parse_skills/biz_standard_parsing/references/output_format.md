# 商务标准输出格式

下列 Markdown 只定义展示分类、列名和层级；实际通过工具提交 content JSON。
正文按全部证据综合，引用独立保存；无依据内容省略，未决事项登记为检索缺口。

```markdown
## 付款条件
| 付款要素 | 具体要求 |
|----------|----------|
|  |  |

## 交付要求
| 交付要素 | 具体要求 |
|----------|----------|
|  |  |

## 验收条款
| 验收要素 | 具体要求 |
|----------|----------|
|  |  |

## 质保与售后服务
| 服务要素 | 具体要求 |
|----------|----------|
|  |  |

## 违约责任
| 违约情形 | 责任内容 |
|----------|----------|
|  |  |

## 保险与担保要求
| 担保类型 | 具体要求 |
|----------|----------|
|  |  |

## 知识产权与保密
| 条款类型 | 具体要求 |
|----------|----------|
|  |  |

## 争议解决
| 解决方式 | 具体内容 |
|----------|----------|
|  |  |

## 合同变更与终止
| 条款类型 | 具体要求 |
|----------|----------|
|  |  |
```

## 内容约束
- 同一内容只归入最相关的一个商务分类，避免重复。
- 付款、交付、验收、质保、违约等条款优先保留原文完整表述，不得简化关键期限、比例、条件。
- 如果条款实际属于人员、业绩、废标或评分模块，直接排除，不写入解析结论。
