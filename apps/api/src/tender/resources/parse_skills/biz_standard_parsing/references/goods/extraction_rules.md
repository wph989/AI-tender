# 商务标准提取规则（货物类）

## 货物类商务标准的核心特征

货物类招标的商务标准围绕**产品认证、制造商资质、供货能力**展开。
与工程类（施工资质）和服务类（服务能力）有本质区别。

---

## 一、货物类特有商务要求

### 1.1 产品认证类
- **强制性认证**：CCC认证、特种设备制造许可
- **自愿性认证**：节能认证、环保标志认证、绿色产品认证
- **检测报告**：第三方检测机构出具，注意时效性

### 1.2 制造商资质类
- **生产许可证**：工业产品生产许可证
- **ISO体系**：ISO9001/ISO14001/ISO45001
- **制造商授权**：代理商投标时的授权函要求

### 1.3 供货能力类
- **生产能力**：年产能/月产能
- **交货期**：从合同签订到交付的时间
- **供货业绩**：类似产品的供货合同
- **仓储/物流**：配送能力、售后服务网点

### 1.4 合同条款类
- **质保期**：通常1-3年，自验收合格之日起
- **售后服务**：响应时间、维修网点、备件供应
- **付款方式**：预付款比例、验收后付款比例

## 三、强制 vs 优选判定规则

### 强制性：
- CCC认证/生产许可证（产品准入门槛）
- 制造商授权函（代理商投标时）
- 最低交货期要求
- 最低质保期要求

### 优选性：
- 额外的产品认证（节能/环保加分）
- 超出资质要求的体系认证
- 超过最低要求的供货业绩
- 更长的质保期承诺

---

## 四、严禁行为
- ❌ 遗漏产品认证/检测报告的强制要求
- ❌ 遗漏"代理商需提供制造商授权函"
- ❌ 混淆"交货期"和"质保期"
- ❌ 混淆"强制性认证"和"自愿性认证"
- ❌ 遗漏售后服务的响应时间要求
