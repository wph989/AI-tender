# 商务要求提取细则（engineering）

以下内容是检索和判断指导，示例名词不代表本项目事实。只使用本次已读原文作依据。

检索付款、交付、验收、质保、违约、保险、知识产权、争议及变更终止等履约条款，不能根据章节叫“商务”就收录资格或评分。
- 每个付款阶段保留支付比例、计算基数、付款前提、发票及相对期限，不能仅写“按合同支付”。 <!-- topics: payment -->
- 区分交付完成、验收通过、质保起算与售后响应；跨块的起算点和例外须一起补读。
- 违约责任保留触发条件、计费基数、比例、周期、上限、解除权及例外。 <!-- topics: liability -->
- 保险和其他履约担保可以收录；投标保证金与履约保证金由保证金专题处理。
- 企业资格、企业业绩、人员、技术方案、评分及报价构成分别属于其他专题，不用“强制/优选”模板替代履约事项。
- 同一条款只归最相关分类；通用合同与专用合同有明确修改时引用双方，不能默认后上传者优先。

## 品类重点

重点核对预付款及扣回、进度款、工程计量、竣工结算、工期顺延、缺陷责任和工程保险；施工资质和建造师准入不是合同履约事项。
