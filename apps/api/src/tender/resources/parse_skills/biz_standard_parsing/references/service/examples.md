# 商务标准解析样例

## 样例 1：资格要求章节

### 输入原文
```
第二章 投标人资格要求
1. 投标人应为在中华人民共和国境内注册的独立法人，持有有效的营业执照
2. 投标人应具有建筑装修装饰工程专业承包一级资质
3. 投标人近3年（2023年1月1日至今）应具有至少2个合同金额不低于500万元的类似项目业绩
4. 投标人应提供2023年度经审计的财务报告，资产负债率不超过70%
5. 投标人未被列入"信用中国"失信被执行人名单
```

### 期望输出
全部5条均为强制性要求，分类为：资格条件(1,2)、业绩要求(3)、财务要求(4)、信誉要求(5)。

## 样例 2：区分强制与加分

### 输入原文
```
商务评分（30分）：
1. 投标人具有ISO9001质量管理体系认证的，得3分
2. 投标人具有ISO14001环境管理体系认证的，得2分
3. 投标人必须具有安全生产许可证，否则资格审查不通过
```

### 期望输出
- 第1、2条为**加分项**（ISO认证加分）
- 第3条为**强制性要求**（无安全生产许可证则不通过资格审查）

## 样例 3：商务条款提取

### 输入原文
```
合同主要条款：
1. 付款方式：合同签订后支付30%预付款，竣工验收合格后支付至95%，质保期满后支付剩余5%
2. 交货期：合同签订后60个日历天内完成全部供货
3. 质保期：验收合格之日起24个月
4. 违约责任：逾期交货每日按合同总价0.5‰支付违约金
```

### 期望输出
4条商务条款全部提取：付款方式（30%+65%+5%三阶段）、交货期（60日历天）、质保期（24个月）、违约金（0.5‰/日）。
