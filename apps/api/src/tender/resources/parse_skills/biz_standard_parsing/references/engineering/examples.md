# 商务标准解析样例（工程类）

## 样例 1：施工招标资格要求

### 输入原文
```
第二章 投标人资格要求
1. 投标人应具有建筑工程施工总承包二级及以上资质，并具有有效的安全生产许可证
2. 投标人近5年（2021年1月1日至今）应具有至少2个单项合同金额不低于2000万元的房屋建筑工程施工业绩，且均已竣工验收合格
3. 拟派项目经理应具有建筑工程专业一级注册建造师执业资格，具有安全生产考核合格证（B证），近3年担任过至少1个单项合同金额不低于3000万元的类似工程项目经理
4. 投标人2022、2023年度经审计的财务报表显示连续盈利，资产负债率不超过75%
5. 本项目接受联合体投标，联合体成员不超过2家，牵头方应具有施工总承包资质
```

### 期望输出
**强制性要求：**
| 序号 | 商务条件 | 类型 | 要求 |
|------|---------|------|------|
| 1 | 施工资质 | 资质类 | 建筑工程施工总承包二级及以上 |
| 2 | 安全生产许可证 | 资质类 | 有效 |
| 3 | 施工业绩 | 业绩类 | 近5年≥2个，单个≥2000万元，房屋建筑工程，已竣工验收 |
| 4 | 项目经理 | 人员类 | 建筑工程专业一级建造师 + B证，近3年≥1个≥3000万元类似项目 |
| 5 | 财务要求 | 财务类 | 连续2年盈利，资产负债率≤75% |
| 6 | 联合体限制 | 其他 | 接受，≤2家，牵头方需施工总承包资质 |

## 样例 2：区分强制与加分（工程类评分表）

### 输入原文
```
商务评分（25分）：
1. 投标人具有建筑工程施工总承包一级资质的得5分，二级的得3分（资格条件为二级及以上）
2. 投标人在资格条件要求的2个业绩基础上，每增加1个类似工程业绩得2分，最高6分
3. 投标人具有ISO9001质量管理体系认证得2分，ISO14001环境管理体系认证得2分
4. 投标人获得省级及以上"守合同重信用"企业称号的得3分
```

### 期望输出
**优选性要求（加分项）：**
| 序号 | 加分条件 | 分值 | 与强制条件的关系 |
|------|---------|------|---------------|
| 1 | 施工总承包一级资质 | 5分 | 强制条件为二级，一级额外加分 |
| 2 | 超出最低数量的业绩 | 每个2分，最高6分 | 强制要求2个，超出部分加分 |
| 3 | ISO9001认证 | 2分 | 独立的加分项 |
| 4 | ISO14001认证 | 2分 | 独立的加分项 |
| 5 | 守合同重信用企业 | 3分 | 独立的加分项 |
