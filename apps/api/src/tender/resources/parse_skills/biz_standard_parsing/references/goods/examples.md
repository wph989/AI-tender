# 商务标准解析样例（货物类）

## 样例 1：设备采购资格要求

### 输入原文
```
投标人资格要求：
1. 投标人应为具有独立法人资格的设备制造商或经授权的代理商
2. 投标产品（中央空调机组）应具有有效的全国工业产品生产许可证
3. 投标产品应通过国家强制性产品认证（CCC认证）
4. 投标产品应具有中国节能产品认证证书（有效期内的）
5. 代理商投标的，应提供设备制造商针对本项目的唯一授权函
6. 投标人近3年应具有至少3个同类设备供货业绩，单个合同金额不低于300万元
7. 投标人应具有完善的售后服务体系，在项目所在地设有售后服务网点
```

### 期望输出
**强制性要求：**
| 序号 | 商务条件 | 类型 | 要求 |
|------|---------|------|------|
| 1 | 生产许可证 | 产品认证类 | 全国工业产品生产许可证（中央空调机组） |
| 2 | CCC认证 | 产品认证类 | 国家强制性产品认证 |
| 3 | 授权函 | 制造商资质类 | 制造商针对本项目的唯一授权函（代理商投标时） |
| 4 | 供货业绩 | 供货能力类 | 近3年≥3个同类设备供货，单个≥300万元 |
| 5 | 售后服务 | 售后服务类 | 项目所在地设有售后服务网点 |

**优选性要求：**
| 序号 | 加分条件 | 类型 |
|------|---------|------|
| 1 | 中国节能产品认证 | 产品认证类（自愿性） |

## 样例 2：售后与质保条款

### 输入原文
```
商务条款：
1. 质保期：自设备验收合格之日起不少于24个月
2. 质保期内免费维修更换零配件，质保期外提供终身有偿维修服务
3. 故障响应时间：接到报修后2小时内响应，24小时内到达现场
4. 备件供应：停产后至少10年内保证零配件供应
```

### 期望输出
- 质保期：≥24个月（自验收合格之日起）
- 质保期内：免费维修+更换零配件
- 质保期外：终身有偿维修
- 响应时间：报修后2小时响应 + 24小时到场
- 备件供应：停产后≥10年
