# 质量判定与验证

质量判断分为运行状态、机器自查和人工裁定。执行 `completed` 只表示该轮结束；机器自查使用 `self_check_passed / needs_review / needs_input / unknown`；人工裁定使用当前快照上的确认、修正或驳回记录。

## 编制门槛

编制上下文只接受当前冻结输入与正文上的人工确认或修正。未确认、驳回、失去来源或过期记录不进入编制。正文相同但资料变化，也不能复用旧人工裁定。

## 程序验证

统一离线检查覆盖类型、分层、工具反馈、引用、预算与草稿发布。独立PostgreSQL检查覆盖锁、配额、事务提交失败、重复消息、恢复、不可变快照与人工裁定一致性。OpenAPI生成类型检查防止前后端契约漂移。

## 语义验收

使用脱敏遗漏、冲突和错误自查样例验证状态边界。真实语义结论由完整原文和各版本轨迹逐项人工核对，记录覆盖、期限、例外、适用范围、未决问题与引文。当前已知真实单Agent语义验收仍失败，详见[稳定性验收](../工程/24-解析Agent稳定性验收.md)。
