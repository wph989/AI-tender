# 动态配置中心

配置中心维护当前登记项、覆盖值、发布版本与逐项确认记录。默认值来自 `config/schema.py`，空库基线同步配置种子；契约测试核对默认值、类型、描述与门禁属性。

## 发布流程

草稿记录实际变化项。L1运行参数按既定生效规则读取；L2解析策略须完成影响清单逐项确认后激活。活动版本由配置端口读取，缓存适配器负责跨进程刷新。回滚采用已发布版本的配置值并追加审计。

任务创建事务同时保存执行预算与配置版本。重试和恢复直接使用创建时快照；分析显式补跑创建新运行并冻结当时预算。每个运行的执行条件保持可追溯。

## 写入约束

只接受当前登记项，拒绝未知键和错误类型。轮询最大间隔不得小于初始间隔，相似度范围为0到1，允许暂停的并发和关闭重试的次数可取0；具体范围见[配置限制清单](../工程/18-配置限制清单.md)。

配置操作模式包括viewer/reviewer/operator/admin：operator修改L1，admin修改L1与L2，其他模式只读。项目尚未接入身份认证，操作模式来自当前请求头。

详细路由和响应契约见[后端API](../设计/05-后端API设计.md)。
