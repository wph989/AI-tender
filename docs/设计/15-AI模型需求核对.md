# AI模型能力核对

当前模型管理使用供应商协议、模型能力、参数、功能绑定、能力测试和调用账六类信息。参数契约维护在 `application/llm/profiles.py` 与 `registry.py`，各供应商实际行为由适配器验证。

核对能力时使用对应语言、嵌入、重排或生图端口，不把语言模型的文本响应当作其他能力证明。图片输入与图片输出分别声明；模型参数更新推进修订号，嵌入空间变化使旧索引失效。

测试结果保留成功、失败或未知状态、实际耗时、脱敏错误、用量和有效期。可控模型测试验证程序规则；真实供应商能力需记录对应配置与响应。模型路由说明见[12](12-LLM管理与模型路由.md)。
