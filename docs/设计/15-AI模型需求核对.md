# AI 模型管理需求核对

更新：2026-10-05。基线：[11-AI模型管理详细设计.md](../../11-AI模型管理详细设计.md)。

此前只有 language、embedding、rerank 三种类型，能力固定，参数仅超时、温度、输出上限和重试。该版本未完整实现基线。本次补齐模型分类、能力与配置链路，但下表仍有未完成项，不能称为全文交付。

## 1. 分类与配置的实际实现

| 基础 kind | 页面细分 | 已实现协议与真实请求契约 |
| --- | --- | --- |
| language | 文本；勾选 image_input 后支持视觉 | OpenAI/兼容 Chat Completions、Responses；Anthropic Messages；Gemini generateContent，图片实际作为输入发送 |
| embedding | 纯文本；文本＋图片多模态 | OpenAI/兼容 embeddings 支持文本与 dimensions；Gemini batchEmbedContents 支持文本/图文与 dimensions、task_type |
| rerank | Rerank · 重排 | 固定 rerank HTTP 契约，top_n 可配置并限制到输入候选数 |
| image_generation | Image · 生图 | OpenAI/兼容 images/generations；Gemini generateContent 图片输出；独立绑定与测试预览 |

这四种基础类型覆盖六类测试场景：文本、视觉、文本嵌入、图文嵌入、重排、生图。音频/视频不在本基线首期支持范围。标准 OpenAI embeddings 不承诺图片支持；不能把 Ollama 文本接口的成功当作图文嵌入证明。

模型表单、编辑、目录导入共用服务端参数 schema。语言参数按协议包含 temperature、max_tokens、top_p、top_k、stop、seed、频率/重复惩罚、推理强度和显式输出预算字段；生图包含适用的尺寸、质量、背景、输出格式/压缩或宽高比/分辨率。模型 supported_parameters 可以进一步收窄。未填写的可选参数不出站，未知参数不能覆写路径、认证或模型身份。
