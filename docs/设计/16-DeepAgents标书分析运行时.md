# 标书分析运行时

API创建冻结资料、专题、标段、Skill和运行预算的报告。执行用例准备各专题运行，Worker通过消息、锁和租约调用执行器。专题使用一个Agent，研究和自查步骤由Skill安排。

数据库运行仓储维护专题队列、跨报告配额、租约、请求预占和调用结算。执行者断连后读取同一运行状态恢复，预算和截止时间保持。重复消息、失效租约和所有权变化不能再次结算。

工作区保存草稿和自查凭据；最终提交原子发布模块成果。报告执行结束后形成不可变数据快照，读取时继续检查来源有效性，人工裁定绑定当前快照。

部署检查点使用 `python -m tender.adapters.pg.analysis.checkpoints`，框架表位于 `agent_runtime`。业务库初始化见[工程17](../工程/17-数据库迁移.md)，完整流程与护栏见[工程14](../工程/14-解析Skill与运行护栏.md)。
