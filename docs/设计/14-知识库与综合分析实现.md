# 知识库与综合分析

知识库用例负责集合、来源、索引和问答，数据库实现位于 `adapters/pg/repositories/knowledge/`。分块与坐标映射属于 `domain/knowledge/` 的纯规则。

## 索引与读取

当前索引分块版本为语义块v2，保留条款正文、章节和跨页原文位置。已建成索引在数据库内排名并有限返回；未建索引从同一原文规则回退，分页补读只扫描所需前缀，不读取余下全文计算总数。

向量空间由绑定模型和参数确定，空间不匹配时不混用向量。词法候选独立召回，向量阈值在融合前过滤，结果不返回向量。来源读取核对公司、集合、文件、版本及解析批次。

## 问答与分析

问答Agent维护自身提交和证据校验。专题分析Agent按Skill研究、草稿、自查和最终提交。两者共用检索会话、模型适配和通用字段反馈，互不依赖对方的业务编排。

分析最终条目由暂存记录和最终选择的ID确定，发布前引用校验及结果计数读取同一选择；最终草稿保存正式业务数据和研究摘要，避免重复复制完整条目。

草稿、自查和最终提交在一次同步操作内复用依赖与原文版本索引，分页正文和进度共用自查结果；下次请求重新核验。草稿回读在当前图内复用序列化文本，草稿、证据、笔记及自查凭据变化后更新缓存；每页只构造请求窗口的分段，保持完整总数、草稿与原文交错和共享证据去重。缓存不进入检查点。正文始终按冻结输出声明从content生成，不接受无声明的手写正文路径。

正式分析记录保存业务JSON和独立证据映射，缺少证据ID或证据映射的记录不能作为完整依据消费。统一快照按冻结输入与正文产生版本；问答关系也从该快照读取。报告详情通过窄字段查询读取执行、质量与运行信息；展示只取Skill协议和所需输出声明，Worker与发布仍读取完整规则。单专题records接口按报告ID和专题键取数，分析页轮询通过报告records接口合并读取全部专题，同一请求复用引文解析和冻结输入核验。服务端每轮先核验当前权限，再对可见响应生成版本，只传输变化专题的正文；前端复用未变化正文，最新进度继续取报告详情，切换报告、单专题错误或整批失败均清除对应缓存版本。读取历史快照仍核对实时来源，人工裁定绑定快照与记录，编制只接受当前已确认或修正的记录。

展示路径先检查独立证据与实时权限，再复制可见正文；证据完整性规则与内部投影共用，内部投影继续保留不可用标记。合并接口将专题范围下推SQL，默认全量读取仍供Worker和发布使用。快照读取后的当前版本检查只查询最新ID，模型等待后与事务内继续重新校验。前置状态或详情读取失败、已有报告从列表消失时清除旧正文、缓存和定位；请求取消不清除新结果，恢复后完整读取。

事务与恢复说明见[架构设计](../工程/11-架构设计.md)，当前物理表见[数据模型](03-数据模型与溯源设计.md)。
