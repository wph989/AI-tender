# 文档解析流水线

文件上传创建文档版本与项目文件关系。PDF直接检查页面几何；Office先通过Gotenberg转换为PDF。原件、PDF与解析产物存入统一存储端口。

MinerU流程包括上传、提交、轮询、解析产物下载与归一化。元素保留原文类型、页码、顺序、锚点和bbox；原文位置用于前端定位，业务模型输出不能重新生成坐标。

## 调度与恢复

任务创建时冻结执行预算。Beat根据实时并发配额派发消息，数据库记录阶段、租约和下次尝试时间。Worker认领后持有任务锁，提前或重复消息不会增加调用次数，也不会越过阶段配额。

网络错误采用当前有界重试和持久退避；远端提交结果未知时保留未知状态。取消仍在远端执行的任务进入等待远端终止的状态，确认远端停止后释放配额。

## 解析后的分析

文档就绪后建立知识来源与语义分块索引。分析报告冻结当前资料和专题配置，每专题一个Agent按Skill研究、自查和提交。文档任务与分析运行分别维护恢复状态，分析细节见[运行护栏](../工程/14-解析Skill与运行护栏.md)。
