# Agent检索与专题汇总

专题Agent加载Skill自主研究、保存草稿、自查、修订和最终提交。工具仅提供授权范围内的原文与工作区操作；程序维护引用、预算、版本和发布事务。

检索采用词法与向量候选融合，已建索引在PostgreSQL精确排名并有限返回；尚未建索引时沿相同规则从原文派生语义块。语义块保留完整条款和跨页位置，模型读取块ID与正文，位置映射由代码维护。

报告模块输出字段、内容、证据以及按专题声明的业务结构。草稿引用与正式业务JSON分开保存；最终提交后生成统一结果快照，人工裁定绑定快照和记录。问答维护自身提交与引用校验，与专题分析共用检索会话和模型基础组件。

具体运行护栏见[工程14](../工程/14-解析Skill与运行护栏.md)，事务及模型边界见[架构设计](../工程/11-架构设计.md)。
