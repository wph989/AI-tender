# 前端展示与原文定位

前端采用Next.js、React、TypeScript与Ant Design。项目页管理资料版本，分析页展示报告、专题进度、机器自查、问题和人工裁定。字段与内容按KV行展示，引用独立呈现。

## 结果与复核

报告执行状态与机器自查、人工复核分别显示。未确认的记录不进入编制；确认或修正绑定当前结果快照，输入变化后的裁定显示过期。自查通过仍需人工核对业务结论。

## PDF定位

`pdfjs-dist`在浏览器渲染PDF、文字层和高亮层。位置使用解析批次、元素锚点、1起始页码与归一化bbox；当前旋转和裁剪通过同一转换函数映射到视口。跨页语义块携带各页位置，点击引文后选择对应页面定位。

PDF下载支持Range；页面按可视范围渲染，尺寸变化使渲染缓存失效。前后端坐标转换共同验证 `packages/contract/coords-vectors.json`。

## API调用

客户端共享请求发送与错误解析，线格式由OpenAPI生成类型约束。长任务通过状态轮询展示，模块进度来自运行记录，不在业务成果中维护进度副本。

删除请求失败时展示错误并保留确认框重试。确认操作采用await模式，防止组件将正常业务错误重新抛为全局未处理异常。

前端验证使用 `pnpm --dir apps/web typecheck` 和 `pnpm --dir apps/web test`。类型检查覆盖应用源码及浏览器夹具，浏览器验证使用 `pnpm --dir apps/web test:e2e`。工作区关闭pnpm执行前自动补装依赖，依赖由开发者显式安装。
