## 自查计算复用

`DraftWorkspace` 的自查计算使用一次同步操作内的 `_ReviewEvaluation`，复用事项、依赖、原文版本和签名索引。分页正文与进度、模型上下文与进度共用 `current_reviews()` 的结果；保存自查和最终提交也复用同一操作内的版本计算。

计算视图不进入工作区或检查点。每次新请求重新读取草稿和原文，原文、草稿版本或依赖变化继续使旧自查失效。

使用真实工作区生成40条通过自查的记录、160块原文，再执行当前分页函数：

| 每次分页请求 | 清理前 | 当前 |
| --- | ---: | ---: |
| 自查状态判断 | 80次 | 40次 |
| 原文版本计算 | 640次 | 160次 |
| 首次返回文本编码 | 200次 | 200次 |
| 后续页返回文本编码 | 0次 | 0次 |
| 已自查记录数 | 40 | 40 |

新增回归验证同一操作只计算一次共享原文版本，并验证下一次操作在原文修改后使自查失效。原有依赖变化、范围、问题与最终提交回归保留。

## 当前补读入口

单测使用独立条款验证有界窗口，数据库批量补读用例使用专题的实际紧凑模式。原文完整性、跨来源拒绝、预算、截断与续读断言继续执行。
