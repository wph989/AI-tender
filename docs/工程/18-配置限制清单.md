核对日期：2026-10-11。以下为本轮实施后的状态，覆盖配置中心全部 39 项、补跑参数，以及模型管理的主要配置。上传大小、分页数量等业务接口限制不属于本清单。

2026-10-12：模型相关项的页面入口已移至「模型管理 → 分析参数」，包括 `analysis.*`、`llm_aided.*`、
`extract.max_inflight`、`extract.strategy.*`。以下配置键、约束、保存和版本发布规则不变。

人工预算上限已取消，保留正数/非负数、比例、协议枚举和权限约束。无人工最大值仍受数据库数值类型、机器资源和供应商能力约束；不代表无限执行。业务库尚未应用 0012，现场启用须先迁移，再重载 API、worker 与 beat。

## 1. 配置中心：全部 39 项

范围与枚举唯一声明在 `config/schema.py::value_rules`；API 返回 minimum/maximum/choices，页面直接读取，补跑请求模型也复用该声明。模型管理使用 `application/model_profiles.py` 的对应声明；数据库仅保留持久化合法性约束。后续调整范围无需再次修改表单、补跑接口和执行流程。

通用类型限制：整数不接受布尔值、字符串或小数；number 必须是有限数值；布尔和字符串必须匹配类型；JSON 必须可序列化。未登记 key 拒绝写入。最大轮询间隔不能小于初始间隔。

## 2. 报告补跑与运行时隐含限制

| 参数或行为 | 实际限制 | 建议 |
| --- | --- | --- |
| 补跑 `max_output_tokens` | 可省略；显式值为整数 ≥1，无人工最大值 | 与配置中心保持一致 |
| 补跑 `timeout_seconds` | 可省略；显式值为整数 ≥1，无人工最大值，与配置中心复用同一规则 | 已统一；0 不再接受，省略时取配置中心值 |
| 补跑 `module_keys` | 最多 13 项，只能使用内置模块 key；省略时补跑失败或已取消模块 | 保留，13 对应当前实际模块数量 |
| 已有运行的预算 | 创建运行时冻结；补跑创建新 attempt 才取当前配置，旧运行账与报告快照不回写 | 保留可审计语义，页面避免称所有预算立即作用于正在运行的任务 |
| 单次输出额度 | 配置了模型 `max_tokens` 时，取它与分析 `max_output_tokens` 的较小值；未配置则用分析额度 | 保留双层预算；页面展示最终有效值，避免只调分析额度仍被模型额度卡住 |
| 证据块预算 | 已登记 `analysis.max_evidence_blocks`，默认 160，整数 ≥1、无人工最大值 | 新建或补跑时冻结预算 |
| 分析图递归步数 | 按模型/工具次数推导为 4×两者之和，分析至少 256、问答至少 128 | 已按运行预算推导，避免固定步数先截断大预算 |
| 上下文压缩触发 | `context_tokens × 80%`，触发值至少 1 | 可保留默认，预算过小时提示固定指令与压缩开销 |
| 业务记录每批提交 | 普通模块最多 3 条，格式模块最多 6 条；可多批提交 | 保留小批校验，但让模型在提示词中明确知道该限制 |

## 4. 配置发布限制

- L1：operator/admin 可写，保存后激活；分析运行预算仍遵循 attempt 快照规则。
- L2/L3：只有 admin 可写，保存为草稿，需要逐项确认变更影响并通过门禁才能激活；同一变更包含这些层时，随版本一起激活。
- 硬门禁：影响项须确认、幻觉与锚点 404 必须为零、回放不能整体失败、通过率不能低于基线；不能强制绕过。
- 软门禁：首次通过率下降超过 2 个百分点时，须强制激活并填写理由。
- 只有 admin 可确认影响、激活及回滚；草稿不能直接回滚，当前生效版本不能重复回滚。
- 变更说明、确认评论、激活/回滚理由最多 1000 字符；一次确认 1–500 项，每项 kind 最多 100 字符、ref 最多 500 字符。

保留权限、类型、审计和数据质量门禁。暂未支持的能力标为只读，避免保存成功却不参与执行。
