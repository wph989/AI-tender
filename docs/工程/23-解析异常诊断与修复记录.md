# 解析异常诊断

诊断从终态复盘档案、运行账和调用账开始。普通日志按日期轮转，分析档案按专题完成时间独立保存；保留路径和时长由 `core/settings.py` 配置。

| 现象 | 核对依据 | 处理方向 |
| --- | --- | --- |
| 工具参数反复错误 | 字段路径、校验原因、完整工具回执 | 给同一Agent准确反馈，核对工具schema |
| 读取范围不足 | 请求窗口、实际交付块、原文分页 | 检查完整元素及额度，保持请求窗口 |
| 正文遗漏或混用程序 | 草稿、自查、修改、最终所选版本和原文 | 核对适用范围、修订与例外，修正专题方法 |
| 自查通过但问题未解决 | 自查凭据、问题ID及最终关联记录 | 保留未决问题，逐项人工验收 |
| 执行中断或重复结算 | 运行所有权、租约、请求预占及事务账 | 恢复原运行，核对幂等结算 |
| 供应商503、429或断流 | 实际HTTP状态、流内错误、用量及结束标记 | 按现有有界重试恢复，半截输出拒绝执行 |

此前真实开标和商务验收暴露程序适用性混用、期限与责任条款遗漏、自查未落实到正文等问题，最新已知完整语义验收仍未通过。离线和可控模型集成只证明程序边界，真实语义验收方法见[24](24-解析Agent稳定性验收.md)。
