# 部署与运行

当前应用进程为 FastAPI、一个 Celery Worker 和 Beat。Worker 消费 `convert,parse,tender,poll,analysis`，默认7个线程；任务并发和派发间隔由配置中心控制。

## 配置与依赖

宿主机运行读取 `apps/api/.env`；Compose 读取根目录 `.env`。模板分别为 `apps/api/.env.example` 和 `.env.example`。数据库、Redis、存储及外部服务地址通过这些文件或环境变量配置。

| 服务 | 用途 |
| --- | --- |
| PostgreSQL | 业务数据、配置、任务、运行账与检查点 |
| Redis | Celery消息、配置缓存 |
| S3或本地目录 | 原件、PDF和MinerU解析产物 |
| Gotenberg | Office转PDF，独立编排位于 `docker/gotenberg/` |
| MinerU | PDF解析，部署协议见[接口调研](../调研/01-接口调研-MinerU.md) |

模型供应商与功能绑定在配置页面维护，密钥由 `LLM_SECRET_KEYS` 加密保存。恢复数据库时使用相同的加密密钥，才能读取已保存的供应商凭据。

## 宿主机运行

依赖安装由开发者执行。前端在项目根目录运行 `pnpm install --frozen-lockfile`；后端在 `apps/api` 运行 `uv sync --group dev`。已有环境直接使用虚拟环境解释器，验证与启动命令不隐式安装依赖。

配置连接后，按[数据库初始化](17-数据库迁移.md)创建当前空库基线及检查点表。在项目根目录启动：

```powershell
& .\scripts\start-backend.ps1
```

脚本识别进程路径与创建时间，并检查实际依赖。API就绪后启动Worker和Beat。需要载入代码或部署参数时，先确认活动任务已经结束，再执行 `& .\scripts\start-backend.ps1 -Force`。状态查询与停止方式见[本地启动指南](../../本地启动指南.md)。

前端在 `apps/web` 运行 `pnpm dev --port 4400`，默认代理到本地API的8300端口；使用其他API地址时设置 `API_PROXY_TARGET`。

## Compose运行

```powershell
# 只启动依赖，应用在宿主机运行。
docker compose up -d

# 应用和依赖一起进入容器。
docker compose --profile app up -d --build
```

应用容器的数据库初始化由 `migrate` 服务完成，API、Worker和Beat依赖初始化成功。Gotenberg通过独立编排启动，`GOTENBERG_URL` 指向其服务地址。无GPU时可用 `docker compose up -d --scale mineru=0` 跳过内置MinerU，另行配置可用解析服务。

`BLOB_STORE_BACKEND=s3` 使用S3；`local` 使用共享目录。宿主机的 `LOCAL_STORAGE_ROOT` 默认是 `apps/api/.storage`，API和Worker必须访问同一目录。Compose本地模式使用共享卷 `/app/storage`，并跳过内置MinIO。修改存储参数后一起重启API和Worker。

## 探针与运行记录

`GET /api/v1/healthz` 表示进程存活。`GET /api/v1/readyz` 检查PostgreSQL、Redis和所选存储，任一失败返回503；启动脚本与Compose通过就绪探针确认应用可以处理请求。模型、转换及解析供应商的故障由对应业务任务报告。

日志记录接口、任务、模型、工具调用及错误摘要，详细规则见[日志基础服务](20-后端日志基础服务.md)。运行状态、自查和人工裁定分别记录；真实语义验收见[稳定性验收](24-解析Agent稳定性验收.md)。

## 验证与备份

代码验证使用 `scripts/check-backend.ps1`；涉及数据库事务、锁、快照、恢复及检索时，还须显式设置独立测试库并运行 `scripts/check-postgres.ps1`。前端在 `apps/web` 执行 `pnpm typecheck`、`pnpm test` 和相应浏览器用例。

数据库备份包含业务表和 `agent_runtime` 检查点，同时备份文件存储和供应商密钥配置。恢复到独立库后核对版本、表、索引、数据量及关键记录内容。容量测量见[读取与检索基线](25-读取与检索容量基线.md)，资源配置按实测数据调整。
